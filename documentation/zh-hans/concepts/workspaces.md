# 工作区

## 核心概念

### 工作区（Workspace）

**工作区**是 AI Company 系统中用于隔离和组织不同任务、项目或环境的逻辑单元。**工作区可以跨多个工作节点存在和运行**，实现真正的分布式协同。

工作区不再局限于单个节点，而是一个可以跨越设备边界的逻辑实体。

#### 工作区的作用

1. **环境隔离**
   - 不同工作区的数据和配置相互隔离
   - 避免任务之间的干扰
   - 支持独立的安全策略

2. **跨节点协同**
   - 工作区可以同时在多个节点上运行
   - 智能体可以在不同节点间迁移和协作
   - 数据自动在多个节点间同步

3. **资源分配**
   - 为每个工作区分配特定的资源（可跨节点）
   - 限制资源使用，防止资源耗尽
   - 优先级调度

4. **上下文管理**
   - 保存工作区的上下文状态
   - 快速切换不同的工作场景
   - 支持工作区的暂停和恢复

#### 工作区类型

| 工作区类型 | 用途 | 特点 |
|-----------|------|------|
| **个人工作区** | 个人日常使用 | 完全私有、灵活配置 |
| **项目工作区** | 特定项目协作 | 可共享、版本控制 |
| **智能体工作区** | AI 智能体运行 | 自动管理、资源优化 |
| **安全工作区** | 敏感任务处理 | 最高安全级别、审计追踪 |
| **临时工作区** | 短期任务 | 自动清理、生命周期短 |

#### 工作区-节点关系

```
工作区（跨节点）
│
├── 工作节点 1 (Windows PC)
│   ├── 工作区实例 A
│   │   ├── 智能体 1
│   │   └── 本地数据缓存
│   └── 工作区实例 B
│       └── ...
│
├── 工作节点 2 (Android 手机)
│   └── 工作区实例 A
│       ├── 智能体 2（迁移自节点 1）
│       └── 本地数据缓存
│
└── 工作节点 3 (服务器)
    └── 工作区实例 A
        ├── 智能体 3（后台运行）
        └── 完整数据副本
```

## 工作区管理

### 工作区创建

1. **创建方式**
   - 手动创建：用户主动创建工作区
   - 自动创建：根据任务需求自动创建
   - 模板创建：基于预设模板创建

2. **工作区配置**
   ```
   工作区配置 {
     name: 工作区名称
     type: personal | project | agent | secure | temp
     nodeIds: [关联节点列表]  // 可跨多个节点
     resources: {
       cpu: CPU 限制（跨节点总和）
       memory: 内存限制（跨节点总和）
       storage: 存储限制（跨节点总和）
     }
     security: {
       encryption: 是否加密
       accessControl: 访问控制
     }
     lifecycle: {
       autoCleanup: 是否自动清理
       ttl: 生存时间
     }
     distribution: {
       preferredNodes: [优先节点]
       failoverNodes: [故障转移节点]
       replicationStrategy: full | partial | selective
     }
   }
   ```

### 工作区分布策略

1. **主-从模式**
   - 一个主节点负责协调
   - 其他节点作为副本
   - 适合读写分离场景

2. **对等模式**
   - 所有节点地位平等
   - 数据在节点间复制
   - 适合高可用性场景

3. **分片模式**
   - 工作区数据分片到不同节点
   - 每个节点负责一部分数据
   - 适合大规模数据场景

### 工作区切换

1. **快速切换**
   - 一键切换工作区
   - 保存当前上下文
   - 恢复目标工作区状态

2. **并行工作区**
   - 支持多个工作区同时运行
   - 工作区间资源隔离
   - 可配置工作区优先级

### 工作区同步

1. **跨节点同步**
   - 工作区数据在多个节点间自动同步
   - 增量同步，减少带宽
   - 冲突解决策略

2. **选择性同步**
   - 可选择同步的节点
   - 可配置同步方向
   - 支持离线编辑

3. **智能体迁移**
   - 智能体可以在工作区的不同节点间迁移
   - 保持智能体状态和上下文
   - 根据资源情况自动调度

## 节点实例管理

每个工作区在关联的节点上都有一个实例：

| 实例状态 | 描述 |
|---------|------|
| **Active** | 实例活跃，正在运行智能体 |
| **Standby** | 实例待命，数据同步中 |
| **Offline** | 节点离线，数据待同步 |
| **Failed** | 实例异常，需要恢复 |

## 安全模型

### 工作区安全

- **工作区加密**：工作区数据加密存储
- **访问控制**：细粒度的访问权限控制
- **审计日志**：完整的操作审计记录
- **节点授权**：控制哪些节点可以加入工作区

## 与工作流的关系

工作区为工作流提供运行环境，工作流在工作区内执行。工作流可以跨工作区的多个节点实例执行，实现分布式任务流转。

详见 [工作流](./workflows.md) 文档了解更多。
