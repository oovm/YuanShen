# 员工（Employee）：Agent

员工（Employee）是一个由**技能合集**组成的智能体（Agent），定义了智能体能做什么、擅长做什么、以及如何与其他智能体协作。

## 概念定义

**员工**是技能的容器和组合体，通过组合不同的技能来形成完整的工作能力。员工本身不是技能，而是技能的集合。

## 核心要素

### 基本信息

- **员工名称**：智能体的标识性名称
- **员工头像**：视觉标识
- **职位**：智能体的角色定位
- **描述**：详细的能力介绍
- **角色类型**：智能体的角色分类

### 技能合集

员工通过组合多种技能来形成工作能力：

- **核心技能**：基础能力（沟通、推理、学习、记忆等）
- **专业技能**：特定领域的专业能力（编程、分析、设计等）
- **工具技能**：使用特定工具的能力（开发工具、设计工具、办公工具等）
- **软技能**：人际交往和团队协作能力

详见 [skills.md](skills.md) 了解详细的技能体系。

### 能力配置

员工可以配置多种能力来扩展其功能：

- **API 集成能力**：调用外部 API 的能力
- **MCP 服务能力**：使用 MCP（Model Context Protocol）服务的能力
- **文件操作能力**：读写文件的能力
- **网络访问能力**：访问网络资源的能力

详见 [capabilities.md](capabilities.md) 了解详细的能力体系。

### 工作风格

- **响应速度**：快速响应 / 深思熟虑
- **决策方式**：果断决策 / 充分咨询
- **沟通风格**：简洁直接 / 详细解释
- **风险偏好**：敢于冒险 / 谨慎保守

## 员工的作用

### 1. 技能组合

- 将多个技能组合成完整的工作能力
- 技能之间协同配合，形成合力
- 灵活应对各种任务场景

### 2. 能力标准化

- 清晰定义智能体的能力边界
- 便于用户选择合适的智能体
- 可以评估和比较不同智能体

### 3. 持续进化

- 智能体可以学习新技能
- 技能可以不断提升和优化
- 可以添加新的能力扩展
- 适应新的需求和场景
