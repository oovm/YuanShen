# 日程/定时任务

日程/定时任务是 AI Company 中基于时间驱动的任务执行机制，用于在指定时间或按固定周期自动执行工作流或任务。

## 核心概念

### 日程（Schedule）

日程是时间驱动任务的容器，定义了任务执行的时间规则和要执行的内容。

### 触发类型

日程支持多种触发类型：

- **一次性触发**：在指定的具体时间执行一次
- **周期性触发**：按固定周期重复执行（如每天、每周、每月等）
- **条件触发**：结合时间和其他条件触发

## 日程结构

一个日程包含以下关键属性：

| 属性 | 说明 |
|-----|------|
| **名称** | 日程的标识名称 |
| **描述** | 日程的详细说明 |
| **触发规则** | 定义日程何时触发的时间表达式 |
| **执行内容** | 日程触发时要执行的工作流或任务 |
| **关联项目** | 日程所属的项目（可选） |
| **状态** | 日程的运行状态（启用/禁用） |

## 触发规则

日程使用标准的 cron 表达式或简化的时间配置来定义触发规则：

- **Cron 表达式**：强大灵活的时间表达式，支持秒、分、时、日、月、周
- **简化配置**：
  - 每天特定时间
  - 每周特定天和时间
  - 每月特定日期和时间
  - 自定义间隔（如每 2 小时）

## 执行内容

日程可以触发以下类型的执行内容：

- **工作流**：执行完整的工作流流程
- **单个任务**：执行特定的单个任务
- **通知提醒**：发送日程提醒通知

## 使用场景

日程/定时任务适用于以下场景：

- **定期报告**：每天/每周自动生成项目进度报告
- **数据同步**：定时同步外部系统数据
- **备份任务**：定期执行数据备份
- **提醒通知**：在重要时间点发送提醒
- **批量处理**：在低峰期执行批量数据处理

## 与其他概念的关系

- **项目**：日程可以关联到特定项目，在项目上下文中执行
- **工作流**：日程通常用于触发工作流的执行
- **任务**：日程也可以直接触发单个任务的执行

## 管理功能

日程提供以下管理功能：

- **启用/禁用**：随时控制日程是否运行
- **手动触发**：支持手动立即执行日程
- **执行历史**：记录日程的每次执行情况和结果
- **失败重试**：执行失败时自动重试机制
