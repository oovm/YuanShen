# 用户工作流

本指南详细介绍了用户在使用 AI Company 系统时的完整工作流程。

## 1. 入门阶段

### 1.1 注册与登录
1. 访问 AI Company 官方网站
2. 点击右上角「登录/注册」按钮
3. 填写注册信息，包括用户名、邮箱和密码
4. 验证邮箱地址
5. 使用注册的账号登录系统

### 1.2 下载客户端
1. 登录成功后，点击首页「立即开始」按钮
2. 根据您的操作系统选择对应的下载版本：
   - Windows（支持 Windows 10/11）
   - macOS（支持 macOS 10.15+）
   - Linux（支持主流发行版）
3. 安装并启动客户端

### 1.3 初始化工作节点
1. 首次启动客户端时，系统会自动识别当前设备为一个工作节点
2. 为工作节点设置名称（例如：「我的笔记本」、「家里的服务器」）
3. 创建第一个工作区（例如：「个人项目」、「工作项目」）

## 2. 搭建组织架构

### 2.1 创建或选择公司模板
1. 进入「公司管理」界面
2. 选择适合的公司模板：
   - **一人公司**：适合个人创业者和超级个体
   - **小型团队**：适合 3-10 人的团队
   - **中型企业**：适合 10-50 人的企业
   - **自定义**：从零开始构建组织架构
3. 如果选择「一人公司」模板，系统会自动创建秘书处和必要的组织架构

### 2.2 配置项目模板
1. 进入「项目管理」界面
2. 创建新项目模板：
   - 设置项目名称和描述
   - 定义项目目标和交付物
   - 配置项目 SOP（标准作业流程）
   - 设定项目里程碑和时间节点
3. 或选择系统预设的项目模板：
   - 产品开发
   - 内容创作
   - 市场推广
   - 客户服务

### 2.3 组建团队
1. 进入「团队管理」界面
2. 创建主团队
3. 根据需要创建子团队（单个员工也可以作为子团队管理）
4. 设置团队的职责和权限范围
5. 配置团队的协作流程

### 2.4 配置员工（智能体）
1. 进入「员工管理」界面
2. 创建或选择智能体技能模板
3. 为智能体配置技能：
   - 专业技能（例如：编程、写作、设计）
   - 工具使用能力（例如：Git、Figma、Photoshop）
   - 沟通风格（例如：正式、简洁、友好）
   - 决策模式（例如：自主、咨询、汇报）
4. 将智能体分配到相应的团队

## 3. 执行项目

### 3.1 启动项目
1. 进入「项目执行」界面
2. 选择要执行的项目模板
3. 将项目分配给一个团队（注意：每个项目同一时间只能交给一个团队负责）
4. 设置项目的具体参数和目标
5. 启动项目

### 3.2 监控项目进度
1. 查看项目仪表盘，了解项目整体进度
2. 查看团队的工作状态和任务分配
3. 查看智能体的执行情况和产出
4. 查看项目里程碑的完成情况

### 3.3 干预和调整
1. 如果需要，可以向团队下达指令或提供反馈
2. 可以调整项目参数或时间节点
3. 可以调用其他子团队协助完成特定任务
4. 可以通过秘书处获取项目的详细报告

### 3.4 项目验收
1. 项目完成后，查看最终交付物
2. 审查项目成果是否符合预期
3. 确认项目验收
4. 保存项目经验和最佳实践

## 4. 管理多个工作节点和工作区

### 4.1 添加新的工作节点
1. 在新设备上安装并登录 AI Company 客户端
2. 新设备会自动注册为新的工作节点
3. 为新工作节点设置名称和描述

### 4.2 管理工作区
1. 在任意工作节点上创建新的工作区
2. 工作区之间相互隔离，可以用于不同的项目或用途
3. 可以在不同工作区之间切换
4. 可以设置工作区的权限和访问控制

### 4.3 跨节点协作
1. 项目可以在多个工作节点之间分配
2. 智能体可以在不同工作节点上运行
3. 数据可以在工作节点之间安全同步
4. 可以监控所有工作节点的状态和资源使用情况

## 5. 最佳实践

### 5.1 一人公司工作流建议
1. 使用「一人公司」模板，充分发挥秘书处的作用
2. 创建多个工作区，分别用于不同类型的项目
3. 配置多个专业智能体，覆盖不同的技能领域
4. 定期通过秘书处审阅所有智能体的工作成果

### 5.2 项目管理建议
1. 为不同类型的项目创建专门的项目模板
2. 详细定义项目 SOP，确保智能体理解期望
3. 设置合理的里程碑，便于监控项目进度
4. 保留成功的项目经验，用于后续项目

### 5.3 智能体配置建议
1. 根据实际需求配置智能体的技能和风格
2. 可以为同一个智能体创建多个配置版本，用于不同场景
3. 观察智能体的工作效果，持续优化配置
4. 利用子团队机制，让智能体之间相互协作
