# 场景二：小型软件产品的独立开发

## 场景描述

一名独立开发者，使用 AI Company 系统独立完成一个软件产品从需求分析到上线发布的完整开发流程。

## 组织架构

- **一人公司**模板
- **秘书处**：负责整体协调和进度把控
- **产品团队**：负责产品规划和设计
  - 产品经理智能体：需求分析、产品设计、编写 PRD
  - UI 设计智能体：界面设计、交互设计、制作原型
- **技术团队**：负责开发和测试
  - 架构智能体：技术选型、架构设计
  - 前端开发智能体：前端代码编写
  - 后端开发智能体：后端代码编写
  - 测试智能体：编写测试用例、执行测试、报告 Bug
- **运维团队**：负责部署和运维
  - 运维智能体：环境配置、部署上线、监控告警

## 工作流程

1. **需求阶段**：产品团队负责需求分析和产品设计
2. **设计阶段**：UI 设计智能体制作界面设计和原型
3. **架构阶段**：架构智能体设计技术架构
4. **开发阶段**：前端和后端智能体并行开发
5. **测试阶段**：测试智能体进行全面测试
6. **部署阶段**：运维智能体部署上线
7. **监控阶段**：运维智能体持续监控系统运行

## 关键配置

- 为开发智能体配置代码规范和最佳实践
- 为测试智能体配置测试策略和质量标准
- 为运维智能体配置部署流程和监控规则
