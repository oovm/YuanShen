# 场景五：市场推广活动策划与执行

## 场景描述

一名市场营销人员，使用 AI Company 系统策划和执行一场市场推广活动。

## 组织架构

- **一人公司**模板
- **秘书处**：负责整体协调和活动效果把控
- **策略团队**：负责活动策略和创意
  - 策划智能体：制定活动策略、提出创意方案
  - 竞品智能体：分析竞品活动、提供参考
- **内容团队**：负责内容创作
  - 文案智能体：撰写活动文案
  - 设计智能体：制作活动素材
- **投放团队**：负责渠道投放
  - 投放智能体：制定投放计划、执行投放
  - 优化智能体：监控投放效果、优化投放策略
- **数据团队**：负责数据分析
  - 分析智能体：收集数据、生成报告
  - 复盘智能体：总结经验、提出改进建议

## 工作流程

1. **策略制定**：策略团队制定活动策略和创意方案
2. **内容制作**：内容团队制作活动文案和素材
3. **投放执行**：投放团队执行渠道投放
4. **效果监控**：优化智能体实时监控效果，及时调整
5. **数据分析**：分析智能体收集数据，生成报告
6. **经验复盘**：复盘智能体总结经验，提出改进建议
