# 场景三：多设备协同的研究项目

## 场景描述

一名研究人员，利用多台设备组成的工作节点网络，开展一个复杂的研究项目。

## 组织架构

- **一人公司**模板
- **秘书处**：负责整体协调和研究进度把控
- **文献调研团队**：负责收集和整理文献
  - 检索智能体：检索相关文献
  - 整理智能体：整理文献笔记、生成综述
- **实验设计团队**：负责实验设计和数据分析
  - 设计智能体：设计实验方案
  - 分析智能体：处理实验数据、生成图表
- **论文写作团队**：负责论文撰写和修改
  - 写作智能体：撰写论文初稿
  - 润色智能体：优化语言、提升表达

## 工作节点配置

- **工作节点 A（高性能服务器）**：
  - 工作区：实验计算
  - 运行智能体：分析智能体（处理大量数据）
- **工作节点 B（个人笔记本）**：
  - 工作区：文献调研
  - 运行智能体：检索智能体、整理智能体
- **工作节点 C（备用设备）**：
  - 工作区：论文写作
  - 运行智能体：写作智能体、润色智能体

## 工作流程

1. **文献调研**：在工作节点 B 上，检索和整理相关文献
2. **实验设计**：设计实验方案，准备实验数据
3. **数据分析**：在工作节点 A 上，运行数据分析任务
4. **论文撰写**：在工作节点 C 上，撰写论文
5. **质量把控**：秘书处审核所有产出，确保质量
