# 场景一：超级个体的内容创作工作室

## 场景描述

一名自由职业者，利用 AI Company 系统搭建自己的内容创作工作室，独立完成从内容策划到发布的全流程工作。

## 组织架构

- **一人公司**模板
- **秘书处**：负责整体协调、质量把控和汇报
- **内容策划团队**：负责选题策划和内容规划
  - 策划智能体：分析热点、提出选题
  - 调研智能体：收集资料、整理数据
- **内容创作团队**：负责内容撰写和编辑
  - 主笔智能体：撰写主要内容
  - 编辑智能体：润色、优化、校对
- **视觉设计团队**：负责配图和视觉元素
  - 设计智能体：制作配图、设计封面
- **分发运营团队**：负责内容发布和运营
  - 运营智能体：发布内容、管理评论、分析数据

## 工作流程

1. **项目启动**：创建「内容创作」项目，分配给内容策划团队
2. **选题策划**：策划智能体提出多个选题，调研智能体收集资料
3. **内容创作**：主笔智能体根据策划撰写内容，编辑智能体润色优化
4. **视觉制作**：设计智能体制作配图和封面
5. **内容分发**：运营智能体将内容发布到各个平台
6. **数据复盘**：运营智能体分析数据，秘书处整理报告

## 关键配置

- 为每个智能体配置专业的写作风格和领域知识
- 为设计智能体配置品牌视觉规范
- 为运营智能体配置各个平台的发布规则
