# 技术选型

## 概述

本文档记录 AI Company 系统的技术选型决策，包括通信协议、发现机制、安全标准等。

## 节点间通信

### 发现机制

系统采用多层节点发现机制：

| 发现方式 | 技术选型 | 用途 |
|---------|---------|------|
| **局域网发现** | mDNS/Bonjour | 自动发现本地网络节点 |
| **云端发现** | 云端目录服务 | 发现远程节点 |
| **手动连接** | 直接地址输入 | 手动指定节点连接 |

### 通信协议

| 协议类型 | 技术选型 | 用途 |
|---------|---------|------|
| **实时通信** | WebSocket | 双向实时通信 |
| **服务调用** | gRPC | 高效的服务间调用 |
| **文件同步** | rsync 或类似协议 | 增量文件同步 |

### 安全通信

| 安全机制 | 技术选型 | 说明 |
|---------|---------|------|
| **传输加密** | TLS 1.3 | 所有通信加密 |
| **节点认证** | 节点证书 | 双向认证 |
| **数据加密** | 端到端加密 | 敏感数据端到端加密 |

## 工作节点相关技术

### 节点类型支持

系统支持以下工作节点类型：
- Windows 个人 PC
- 服务器
- Android 手机
- iOS 手机
- 平板设备
- IoT 设备

### 节点状态

| 状态 | 描述 |
|------|------|
| **Online** | 节点在线且空闲 |
| **Busy** | 节点在线但忙碌 |
| **Offline** | 节点离线 |
| **Maintenance** | 节点维护中 |

## 存储技术选型

参考 [data-models.md](./data-models.md) 了解详细的存储架构和技术选型。

### 数据库选型

| 数据库 | 用途 | 场景 |
|-------|------|------|
| **SQLite** | 轻量级关系型数据库 | 单机部署 |
| **PostgreSQL** | 企业级关系型数据库 | 生产环境 |

### 对象存储选型

| 存储类型 | 用途 | 场景 |
|---------|------|------|
| **文件系统（FS）** | 本地文件存储 | 单机部署 |
| **S3** | 对象存储服务 | 生产环境和云部署 |

## 技术选型原则

1. **开源优先**：优先选择成熟的开源技术
2. **标准化**：遵循行业标准和最佳实践
3. **可扩展**：选择支持水平扩展的技术
4. **安全性**：优先考虑安全性和隐私保护
5. **性能**：确保技术选型满足性能要求
