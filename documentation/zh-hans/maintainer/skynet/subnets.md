# 子网模型

## 子网标识

每个子网拥有唯一 ID `subnet_id = blake3(任意字节)`，可由创建者生成。主网是预定义的子网，ID 固定为全零（`0x00...`）。

## 子网类型

子网类型是一个开放的字符串标识，用于区分子网的功能和用途，客户端可以根据子网类型决定是否加载和如何处理该子网。

**常见的子网类型示例**：

| 子网类型 | 说明 | 用途示例 |
|---------|------|---------|
| **organization** | 组织子网 | 用于组织、公司的通信和协作 |
| **community** | 社区子网 | 用于普通社区、兴趣小组的通信 |
| **private** | 私有子网 | 用于小型私密群组通信 |

**子网类型的作用**：
- 客户端可以根据子网类型决定是否加载和如何处理该子网
- 不同类型的子网可以有不同的功能特性和权限策略
- 客户端可以根据类型选择性地加载和显示子网
- 子网类型是开放的，应用可以定义自己的类型

## 子网元信息

每个子网包含元信息，用于描述子网的基本属性和功能：

| 属性 | 说明 | 类型 |
|-----|------|------|
| **subnet_type** | 子网类型 | 字符串（开放类型，如 organization/community/private） |
| **subnet_version** | 子网类型版本 | 字符串（如 "1.0.0"） |
| **name** | 子网名称 | 字符串 |
| **description** | 子网描述 | 字符串（可选） |
| **icon** | 子网图标 | URL 或哈希（可选） |
| **created_at** | 创建时间 | 时间戳 |
| **created_by** | 创建者 | user_id |
| **features** | 功能特性列表 | 字符串数组（可选） |
| **metadata** | 自定义元数据 | JSON 对象（可选） |

**子网元信息的作用**：
- 客户端通过 `subnet_type` 判断是否支持该子网
- `subnet_type_version` 用于版本兼容性检查
- `features` 列表声明子网支持的功能特性
- `metadata` 可用于存储类型特定的扩展信息

## 子网模型概念

Skynet 采用子网模型，每个独立的通信系统或社区都是一个子网：
- 每个子网有自己的用户、联系人、群组
- 用户可以同时加入多个子网，使用同一个 `auth_id`
- 每个子网有独立的联系人和群组（联系人是子网内部概念）

## 子网核心标识

Skynet 作为去中心化通信协议，子网有三个核心标识：

| 标识 | 说明 | 作用 |
|-----|------|------|
| **auth_id** | 用户全局身份 ID | 跨子网唯一标识用户，类似真名。**Skynet 协议的最高机密，仅用于身份认证，绝不应在子网内部数据中泄露或存储。** |
| **user_id** | 用户在子网内的本地 ID | 子网内本地标识，类似昵称/网名，用于隐私保护。**子网内部所有数据只使用 user_id。** |
| **channel_id** | 频道/群组 ID | 标识子网内的一个聊天群组或频道 |

## 子网数据

每个子网维护以下数据，并采用**多节点复制**存储：

### 1. 子网元信息

- **subnet_type**：子网类型（开放字符串，如 organization/community/private）
- **subnet_type_version**：子网类型版本
- **name**：子网名称
- **description**：子网描述（可选）
- **icon**：子网图标（可选）
- **created_at**：创建时间
- **created_by**：创建者的 user_id
- **features**：功能特性列表（可选）
- **metadata**：自定义元数据（可选）

### 2. 成员列表
- **user_id**：用户在子网内的本地 ID（子网内唯一，可选）
- **身份公钥**：用户的 Ed25519 公钥（用于验证签名）
- **角色**：管理员 / 普通成员
- **加入时间**：用户加入子网的时间
- **设备公钥列表**：用户在该子网内使用的设备公钥（用于端到端加密）
- **联系人列表**：该用户在子网内的联系人（子网内部概念，只使用 user_id）
- **用户元信息（Profile）**：
  - **avatar**：头像（资源引用或 URL，可选）
  - **nickname**：昵称（子网内显示名称，可选）
  - **bio**：个人简介（可选）
  - **status_text**：自定义状态文本（如"正在开会"、"外出吃饭"，可选）
  - **presence_status**：在线状态（online/busy/away/offline，可选）
  - **last_active_at**：最后活跃时间（时间戳，可选）
  - **updated_at**：元信息更新时间（时间戳，可选）
  - **device_info**：设备信息（JSON 对象，可选，如设备类型、操作系统等）

**注意**：`auth_id` 仅用于初始身份认证，绝不应存储在子网成员列表或任何子网内部数据中。

### 2.1 子网模式：开放 vs 封闭
子网支持两种运行模式：
| 模式 | 说明 | 适用场景 |
|------|------|---------|
| **封闭子网** | 加入需要管理员审核，防止女巫攻击 | 企业、组织、私密社区 |
| **开放子网** | 任何人可自由加入，无需审核 | 公开社区、兴趣小组 |

子网创建时指定模式，后续可由管理员修改。

### 3. 频道列表
- **channel_id**：频道/群组的唯一 ID
- **频道名称**：群组名称
- **创建者**：创建者的 user_id
- **创建时间**：创建时间
- **成员列表**：频道成员的 user_id 列表
- **频道类型**：私聊 / 群聊 / 公告频道

### 4. 权限策略
- 谁可以添加/移除成员
- 谁可以创建/删除频道
- 谁可以修改频道信息

### 5. 资源（Resource）

资源是子网内可访问的实体，由子网维护节点存储和管理。详见 [资源模型](./resources.md)。

### 6. 信息（Message）

信息是子网内传递的内容单元，用于用户间通信。详见 [消息模型](./messages.md)。

## 子网维护节点

每个子网由一组服务节点（称为**维护节点**）负责存储和同步数据。创建子网时，创建者可指定初始维护节点（通常是自己信任的节点），后续可通过子网内投票或管理员指派增加/移除维护节点。

维护节点之间通过**拜占庭容错复制**保持数据一致。
