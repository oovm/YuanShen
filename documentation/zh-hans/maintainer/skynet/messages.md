# 消息模型

消息是子网内传递的内容单元，用于用户间通信。

## 消息属性

| 属性 | 说明 | 类型 |
|-----|------|------|
| **message_id** | 消息唯一 ID | 字符串 |
| **channel_id** | 频道 ID | 频道 ID（群聊）或空（私聊） |
| **sender_id** | 发送者 ID | user_id |
| **recipient_id** | 接收者 ID | user_id（私聊时使用） |
| **message_type** | 消息类型 | 字符串（如 text/image/file/resource 等，开放类型） |
| **content** | 消息内容 | 结构化数据（JSON 对象或加密的结构化数据） |
| **content_encrypted** | 是否加密 | 布尔值 |
| **resource_refs** | 资源引用列表 | resource_id 数组（可选） |
| **reply_to** | 回复的消息 ID | message_id（可选） |
| **thread_id** | 线程 ID | message_id（可选，用于消息线程） |
| **mentions** | 提及列表 | 提及对象数组（可选） |
| **is_pinned** | 是否置顶 | 布尔值（可选，默认 false） |
| **pinned_at** | 置顶时间 | 时间戳（可选） |
| **pinned_by** | 置顶者 ID | user_id（可选） |
| **status** | 消息状态 | 字符串（可选，如 sending/sent/delivered/read/recalled） |
| **delivered_at** | 送达时间 | 时间戳（可选） |
| **read_at** | 已读时间 | 时间戳（可选） |
| **created_at** | 创建时间 | 时间戳 |
| **edited_at** | 编辑时间 | 时间戳（可选） |
| **deleted_at** | 删除时间 | 时间戳（可选，软删除） |
| **metadata** | 自定义元数据 | JSON 对象（可选） |

## 消息类型

消息类型是开放的字符串标识，常见示例：

| 消息类型 | 说明 |
|---------|------|
| **text** | 文本消息 |
| **image** | 图片消息 |
| **file** | 文件消息 |
| **resource** | 资源引用消息 |
| **link** | 链接消息 |
| **system** | 系统消息 |

## 消息内容格式

- 消息内容是**结构化数据**（通常为 JSON 对象）
- 不是固定的 Markdown 或 HTML 格式
- 客户端根据 `message_type` 和 `content` 结构自主决定如何渲染
- 文本内容可以包含 Markdown、HTML 等格式标签，但这由客户端选择是否解析和渲染

### 消息类型内容结构示例

- **text**：文本消息
  - content 包含 `text` 字段（纯文本、Markdown、HTML 等，由客户端决定渲染方式）
- **image**：图片消息
  - content 包含 `resource_id` 字段引用图片资源
  - 可选包含 `caption` 字段（图片说明）
- **file**：文件消息
  - content 包含 `resource_id` 字段引用文件资源
  - 可选包含 `filename`、`size` 等元数据
- **resource**：资源引用消息
  - content 包含 `resource_id` 字段
- **link**：链接消息
  - content 包含 `url` 字段
  - 可选包含 `title`、`description`、`preview_image` 等预览信息
- **system**：系统消息（如成员加入、频道创建等）
  - content 包含 `event_type`、`event_data` 等字段

## 消息操作

- **消息发送**：发送消息到频道或私聊，端到端加密（可选）
- **消息接收**：从维护节点获取新消息
- **消息编辑**：编辑已发送的消息，保留编辑历史
- **消息删除**：标记消息为已删除（软删除）
- **消息回复**：回复特定消息
- **消息历史**：获取频道或私聊的历史消息

## 消息安全

- 支持端到端加密，只有通信双方能解密
- 消息内容哈希用于完整性验证
- 发送者签名用于身份验证
- 服务节点无法访问加密的消息内容

## 子网隔离原则

- 消息**不跨子网**传递，每个子网是独立的通信域
- 如需跨子网转发消息，必须**复制**到目标子网，而非直接引用
- 复制后，目标子网中的副本拥有独立的生命周期

## 消息状态管理（可选扩展）

子网可选择启用消息状态跟踪功能，提供更丰富的消息体验：

| 状态 | 说明 |
|-----|------|
| **发送中** | 消息已提交到维护节点，正在处理 |
| **已发送** | 消息已存储到维护节点，等待接收 |
| **已送达** | 消息已推送给接收者的在线设备 |
| **已读** | 接收者已阅读该消息 |
| **已撤回** | 发送者已撤回该消息 |

### 消息状态操作（可选）

- **状态更新**：接收者设备在线时，自动更新为"已送达"
- **已读回执**：接收者阅读消息后，发送已读通知（可选）
- **消息撤回**：发送者在一定时间内可撤回消息（可选）
- **状态可见性**：可配置谁能看到消息状态（仅发送者/仅双方/所有人）

## 消息表情反应（Reaction）

消息表情反应是用户对消息的情感反馈。

### 反应属性

| 属性 | 说明 | 类型 |
|-----|------|------|
| **reaction_id** | 反应唯一 ID | 字符串 |
| **message_id** | 目标消息 ID | message_id |
| **user_id** | 添加反应的用户 | user_id |
| **emoji** | 表情 | 字符串（如 "👍"、"❤️"、"🎉"）或自定义表情 ID |
| **created_at** | 添加时间 | 时间戳 |

### 反应操作

- **添加反应**：用户对消息添加表情反应
- **撤销反应**：用户撤销自己添加的反应
- **查询反应**：获取某消息的所有反应列表
- **查看用户**：查看添加了特定表情的用户列表

### 反应特性

- 支持标准 Unicode 表情
- 支持自定义表情（需在子网级别定义）
- 同一用户对同一消息只能添加一次相同表情
- 同一用户对同一消息可以添加多个不同表情

## 消息置顶（Pin）

消息置顶用于标记重要消息，使其在频道或私聊顶部显示。

### 置顶属性

| 属性 | 说明 | 类型 |
|-----|------|------|
| **pin_id** | 置顶唯一 ID | 字符串 |
| **message_id** | 被置顶的消息 ID | message_id |
| **channel_id** | 频道 ID | 频道 ID（群聊）或空（私聊） |
| **pinned_by** | 置顶者 ID | user_id |
| **pinned_at** | 置顶时间 | 时间戳 |
| **order** | 排序位置 | 整数（可选，用于手动排序） |

### 置顶操作

- **置顶消息**：将消息置顶到频道或私聊顶部
- **取消置顶**：取消消息的置顶状态
- **获取置顶列表**：获取频道或私聊的所有置顶消息
- **调整顺序**：调整置顶消息的显示顺序

### 置顶权限

- 可配置谁有权限置顶消息：
  - 仅管理员
  - 仅消息发送者
  - 所有成员
  - 自定义角色

## 消息线程（Thread）

消息线程用于在特定消息下进行深入讨论，不影响主聊天流。

### 线程属性

| 属性 | 说明 | 类型 |
|-----|------|------|
| **thread_id** | 线程 ID | message_id（即父消息的 message_id） |
| **parent_message_id** | 父消息 ID | message_id |
| **channel_id** | 频道 ID | 频道 ID（群聊）或空（私聊） |
| **created_by** | 线程创建者 | user_id |
| **created_at** | 线程创建时间 | 时间戳 |
| **message_count** | 线程内消息数量 | 整数 |
| **last_message_at** | 最后消息时间 | 时间戳 |

### 线程消息

线程中的消息与普通消息类似，但有以下区别：
- 线程消息的 `thread_id` 字段设置为父消息的 `message_id`
- 线程消息在 UI 中独立显示
- 可折叠/展开线程

### 线程操作

- **创建线程**：在某消息下创建回复线程
- **发送线程消息**：在线程内发送消息
- **查看线程**：查看线程内的所有消息
- **折叠/展开线程**：控制线程的显示状态
- **线程通知**：可配置是否接收线程内消息的通知

## 消息提及（Mention）

消息提及用于提醒特定用户或群组。

### 提及对象类型

| 类型 | 说明 | 示例 |
|-----|------|------|
| **user** | 提及特定用户 | @alice |
| **channel** | 提及频道所有成员 | @所有人、@channel |
| **role** | 提及特定角色 | @管理员、@开发组 |

### 提及属性

| 属性 | 说明 | 类型 |
|-----|------|------|
| **mention_type** | 提及类型 | user/channel/role |
| **mention_id** | 提及对象 ID | user_id 或 role_id |
| **mention_name** | 提及显示名称 | 字符串 |
| **offset** | 在文本中的起始位置 | 整数（可选，用于文本高亮） |
| **length** | 在文本中的长度 | 整数（可选，用于文本高亮） |

### 提及操作

- **添加提及**：在消息中添加提及
- **解析提及**：客户端解析消息中的提及
- **发送通知**：被提及的用户收到通知
- **高亮显示**：被提及的部分在消息中高亮显示

### 提及内容结构示例

对于 text 类型的消息，content 可以包含：
```json
{
  "text": "大家好，@alice 请查看这个文档",
  "mentions": [
    {
      "mention_type": "user",
      "mention_id": "user_123",
      "mention_name": "alice",
      "offset": 5,
      "length": 6
    }
  ]
}
```
