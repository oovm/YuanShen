# 用户元信息（Profile）

用户元信息描述用户的公开信息，包括头像、昵称、个人简介、在线状态等。

## 元信息属性

| 属性 | 说明 | 类型 |
|-----|------|------|
| **user_id** | 用户 ID | user_id |
| **subnet_id** | 子网 ID | subnet_id |
| **avatar** | 头像 | 资源引用或 URL（可选） |
| **nickname** | 昵称 | 子网内显示名称（可选） |
| **bio** | 个人简介 | 字符串（可选） |
| **status_text** | 自定义状态文本 | 字符串（可选，如"正在开会"、"外出吃饭"） |
| **presence_status** | 在线状态 | 枚举（online/busy/away/offline，可选） |
| **last_active_at** | 最后活跃时间 | 时间戳（可选） |
| **updated_at** | 元信息更新时间 | 时间戳（可选） |
| **device_info** | 设备信息 | JSON 对象（可选，如设备类型、操作系统等） |

## 在线状态类型

| 状态 | 说明 | 图标 |
|-----|------|------|
| **online** | 用户当前活跃，正在使用客户端 | 🟢 |
| **busy** | 用户在线但忙碌，可能无法及时回复 | 🔴 |
| **away** | 用户在线但离开一段时间（如 5 分钟无操作） | 🟡 |
| **offline** | 用户不在线或没有活动连接 | ⚪ |

## 在线状态更新机制

### 客户端触发更新

- **上线**：客户端连接到服务节点时，自动设置为"online"状态
- **活跃**：用户有操作（发送消息、查看频道等）时，更新最后活跃时间
- **离开**：客户端检测到用户一段时间（如 5 分钟）无操作时，自动设置为"away"状态
- **忙碌**：用户可手动设置为"busy"状态
- **下线**：客户端断开连接时，自动设置为"offline"状态

### 服务节点管理

- 服务节点维护用户的在线状态
- 通过心跳机制检测用户是否在线
- 状态变化时，广播给相关用户（如同一频道的成员）

## 元信息可见性

- 用户元信息在子网内公开可见
- 可配置谁能看到元信息：
  - 所有人
  - 仅联系人
  - 仅同一频道成员
  - 自定义
- 敏感字段（如 device_info）可单独配置可见性

## 元信息操作

- **查看元信息**：查看其他用户的元信息
- **更新元信息**：更新自己的头像、昵称、个人简介
- **设置在线状态**：手动设置自己的在线状态（online/busy/away）
- **设置状态文本**：设置自定义状态文本
- **清除状态**：清除自定义状态，使用默认状态

## 通知机制

- 用户元信息变化时，可选择性地通知相关用户
- 支持状态变化通知开关
- 可配置关注特定用户的元信息变化

## 隐私考虑

- 用户元信息是公开的，但不包含敏感信息
- 可选择隐藏在线状态
- 设备信息是可选的，用户可选择不共享
- 支持元信息部分隐藏（如只显示昵称，不显示头像）
