# 资源模型

资源是子网内可访问的实体，由子网维护节点存储和管理。

## 资源属性

| 属性 | 说明 | 类型 |
|-----|------|------|
| **resource_id** | 资源唯一 ID | 字符串 |
| **resource_type** | 资源类型 | 字符串（如 file/image/document/link 等，开放类型） |
| **name** | 资源名称 | 字符串 |
| **description** | 资源描述 | 字符串（可选） |
| **content_hash** | 资源内容哈希 | blake3 哈希（用于验证完整性） |
| **content_uri** | 资源内容存储位置 | URI（可选，如 IPFS CID、本地存储等） |
| **size** | 资源大小 | 整数（字节） |
| **created_at** | 创建时间 | 时间戳 |
| **created_by** | 创建者 | user_id |
| **updated_at** | 更新时间 | 时间戳（可选） |
| **updated_by** | 更新者 | user_id（可选） |
| **version** | 版本号 | 整数 |
| **permissions** | 权限设置 | JSON 对象（可选） |
| **metadata** | 自定义元数据 | JSON 对象（可选） |

## 资源类型

资源类型是开放的字符串标识，常见示例：

| 资源类型 | 说明 |
|---------|------|
| **file** | 通用文件 |
| **image** | 图片文件 |
| **document** | 文档文件 |
| **video** | 视频文件 |
| **audio** | 音频文件 |
| **link** | 链接资源 |

## 资源操作

- **资源上传**：创建新资源，计算 content_hash，存储内容
- **资源下载**：根据 resource_id 获取资源，验证 content_hash
- **资源更新**：更新资源内容，增加版本号，保留历史版本
- **资源删除**：标记资源为已删除（软删除）
- **资源查询**：搜索和筛选资源列表

## 资源权限

- 资源创建者可设置访问权限
- 支持只读、读写、管理等权限级别
- 可授权给特定用户、角色或整个频道

## 子网隔离原则

- 资源**不跨子网**共享，资源仅在所属子网内可访问
- 如需跨子网使用资源，必须**复制**到目标子网，而非直接引用
- 复制后，目标子网中的副本拥有独立的生命周期和权限
