# 시나리오 2: 소규모 소프트웨어 제품의 독립 개발

## 시나리오 설명

한 독립 개발자가 AI Company 시스템을 사용하여 소프트웨어 제품의 요구 분석부터 출시까지의 완전한 개발 프로세스를 독립적으로 완료합니다.

## 조직 아키텍처

- **1인 회사** 템플릿
- **비서실**: 전체 조정과 진행 관리 담당
- **제품 팀**: 제품 기획과 디자인 담당
  - 제품 매니저 에이전트: 요구 분석, 제품 디자인, PRD 작성
  - UI 디자인 에이전트: 인터페이스 디자인, 상호작용 디자인, 프로토타입 제작
- **기술 팀**: 개발과 테스트 담당
  - 아키텍트 에이전트: 기술 선택, 아키텍처 디자인
  - 프론트엔드 개발 에이전트: 프론트엔드 코드 작성
  - 백엔드 개발 에이전트: 백엔드 코드 작성
  - 테스트 에이전트: 테스트 케이스 작성, 테스트 실행, 버그 보고
- **운영 팀**: 배포와 운영 담당
  - 운영 에이전트: 환경 구성, 배포 출시, 모니터링 알림

## 워크플로우

1. **요구 단계**: 제품 팀이 요구 분석과 제품 디자인 담당
2. **디자인 단계**: UI 디자인 에이전트가 인터페이스 디자인과 프로토타입 제작
3. **아키텍처 단계**: 아키텍트 에이전트가 기술 아키텍처 디자인
4. **개발 단계**: 프론트엔드와 백엔드 에이전트가 병렬 개발
5. **테스트 단계**: 테스트 에이전트가 전면 테스트 진행
6. **배포 단계**: 운영 에이전트가 배포 출시
7. **모니터링 단계**: 운영 에이전트가 지속적으로 시스템 실행 모니터링

## 핵심 구성

- 개발 에이전트에 코드 규범과 모범 사례 구성
- 테스트 에이전트에 테스트 전략과 품질 표준 구성
- 운영 에이전트에 배포 프로세스와 모니터링 규칙 구성
