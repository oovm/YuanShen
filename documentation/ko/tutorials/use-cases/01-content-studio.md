# 시나리오 1: 슈퍼 인디비주얼의 콘텐츠 창작 스튜디오

## 시나리오 설명

한 프리랜서가 AI Company 시스템을 활용하여 자신의 콘텐츠 창작 스튜디오를 구축하고, 콘텐츠 기획부터 출시까지의 전체 프로세스 작업을 독립적으로 완료합니다.

## 조직 아키텍처

- **1인 회사** 템플릿
- **비서실**: 전체 조정, 품질 관리 및 보고서 담당
- **콘텐츠 기획 팀**: 주제 선정 기획과 콘텐츠 계획 담당
  - 기획 에이전트: 핫스팟 분석, 주제 제안
  - 조사 에이전트: 자료 수집, 데이터 정리
- **콘텐츠 창작 팀**: 콘텐츠 작성과 편집 담당
  - 주필 에이전트: 주요 콘텐츠 작성
  - 편집 에이전트: 윤문, 최적화, 교정
- **비주얼 디자인 팀**: 이미지와 비주얼 요소 담당
  - 디자인 에이전트: 이미지 제작, 표지 디자인
- **배포 운영 팀**: 콘텐츠 출시와 운영 담당
  - 운영 에이전트: 콘텐츠 출시, 댓글 관리, 데이터 분석

## 워크플로우

1. **프로젝트 시작**:「콘텐츠 창작」프로젝트를 생성하여 콘텐츠 기획 팀에 할당
2. **주제 기획**: 기획 에이전트가 여러 주제를 제안하고, 조사 에이전트가 자료 수집
3. **콘텐츠 창작**: 주필 에이전트가 기획에 따라 콘텐츠를 작성하고, 편집 에이전트가 윤문 최적화
4. **비주얼 제작**: 디자인 에이전트가 이미지와 표지 제작
5. **콘텐츠 배포**: 운영 에이전트가 콘텐츠를 각 플랫폼에 출시
6. **데이터 복기**: 운영 에이전트가 데이터 분석하고, 비서실이 보고서 정리

## 핵심 구성

- 각 에이전트에 전문적인 작문 스타일과 분야 지식 구성
- 디자인 에이전트에 브랜드 비주얼 규범 구성
- 운영 에이전트에 각 플랫폼의 출시 규칙 구성
