# 실천 제안

## 1. 작은 것부터 시작

먼저 간단한 시나리오부터 시작하여 시스템에 익숙해진 후 점진적으로 복잡도를 높이세요.

## 2. 템플릿을 충분히 활용

시스템은 여러 회사 템플릿과 프로젝트 템플릿을 제공하므로, 필요에 따라 적합한 템플릿을 시작점으로 선택할 수 있습니다.

## 3. 지속적으로 구성 최적화

에이전트의 작업 효과를 관찰하고 지속적으로 그 구성과 스킬을 최적화하세요.

## 4. 비서실을 잘 활용

비서실은 1인 회사의 핵심이며, 그 조정과 품질 관리 기능을 충분히 활용하세요.

## 5. 하위 팀을 유연하게 활용

하위 팀 메커니즘은 에이전트 간에 더 나은 협업을 가능하게 하며, 유연하게 활용하면 효율성을 높일 수 있습니다.
