# 시나리오 5: 시장 홍보 활동 기획과 실행

## 시나리오 설명

한 마케팅 담당자가 AI Company 시스템을 사용하여 시장 홍보 활동을 기획하고 실행합니다.

## 조직 아키텍처

- **1인 회사** 템플릿
- **비서실**: 전체 조정과 활동 효과 관리 담당
- **전략 팀**: 활동 전략과 크리에이티브 담당
  - 기획 에이전트: 활동 전략 수립, 크리에이티브 방안 제안
  - 경쟁사 에이전트: 경쟁사 활동 분석, 참고 자료 제공
- **콘텐츠 팀**: 콘텐츠 창작 담당
  - 카피라이터 에이전트: 활동 카피 작성
  - 디자인 에이전트: 활동 소재 제작
- **게재 팀**: 채널 게재 담당
  - 게재 에이전트: 게재 계획 수립, 게재 실행
  - 최적화 에이전트: 게재 효과 모니터링, 게재 전략 최적화
- **데이터 팀**: 데이터 분석 담당
  - 분석 에이전트: 데이터 수집, 보고서 생성
  - 복기 에이전트: 경험 종합, 개선 제안 제시

## 워크플로우

1. **전략 수립**: 전략 팀이 활동 전략과 크리에이티브 방안 수립
2. **콘텐츠 제작**: 콘텐츠 팀이 활동 카피와 소재 제작
3. **게재 실행**: 게재 팀이 채널 게재 실행
4. **효과 모니터링**: 최적화 에이전트가 실시간으로 효과 모니터링하고 즉시 조정
5. **데이터 분석**: 분석 에이전트가 데이터 수집하고 보고서 생성
6. **경험 복기**: 복기 에이전트가 경험을 종합하고 개선 제안 제시
