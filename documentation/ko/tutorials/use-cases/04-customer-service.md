# 시나리오 4: 자동화된 고객 서비스 센터

## 시나리오 설명

한 소규모 기업이 AI Company 시스템을 사용하여 자동화된 고객 서비스 센터를 구축하고, 고객 상담과 애프터 서비스 문제를 처리합니다.

## 조직 아키텍처

- **소규모 팀** 템플릿
- **비서실**: 전체 조정과 서비스 품질 관리 담당
- **일선 고객 서비스 팀**: 직접 고객 응대 담당
  - 응대 에이전트: 고객 greet, 문제 이해
  - 분류 에이전트: 문제 유형 판단, 해당 팀에 할당
- **기술 지원 팀**: 기술 문제 처리 담당
  - 기술 에이전트: 기술 문제 답변, 해결 방안 제공
  - 업그레이드 에이전트: 복잡한 문제 처리, 필요시 인간에게 전달
- **애프터 서비스 팀**: 애프터 서비스 문제 처리 담당
  - 애프터 서비스 에이전트: 반품/환불 등 문제 처리
  - 재방문 에이전트: 고객 만족도 팔로우업
- **지식 베이스 팀**: 지식 베이스 유지보수 담당
  - 업데이트 에이전트: 지식 베이스 내용 업데이트
  - 분석 에이전트: 자주 묻는 질문 분석, 지식 베이스 최적화

## 워크플로우

1. **고객 응대**: 응대 에이전트가 고객을 greet하고 문제 이해
2. **문제 분류**: 분류 에이전트가 문제 유형 판단하고 해당 팀에 할당
3. **문제 처리**: 해당 팀의 에이전트가 문제 처리
4. **복잡 업그레이드**: 문제가 복잡하면 업그레이드 에이전트 개입하거나 인간에게 전달
5. **고객 재방문**: 재방문 에이전트가 고객 만족도 팔로우업
6. **지식 업데이트**: 분석 에이전트가 데이터 분석하고, 업데이트 에이전트가 지식 베이스 업데이트

## 핵심 구성

- 응대 에이전트에 친절한 커뮤니케이션 스타일 구성
- 기술 에이전트에 제품 지식과 자주 묻는 질문 답변 구성
- 지식 베이스 팀에 지식 업데이트 프로세스와 품질 표준 구성
