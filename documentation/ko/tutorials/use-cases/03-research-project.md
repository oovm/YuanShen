# 시나리오 3: 다중 디바이스 협업의 연구 프로젝트

## 시나리오 설명

한 연구자가 여러 대의 디바이스로 구성된 작업 노드 네트워크를 활용하여 복잡한 연구 프로젝트를 진행합니다.

## 조직 아키텍처

- **1인 회사** 템플릿
- **비서실**: 전체 조정과 연구 진행 관리 담당
- **문헌 조사 팀**: 문헌 수집과 정리 담당
  - 검색 에이전트: 관련 문헌 검색
  - 정리 에이전트: 문헌 노트 정리, 종합 리뷰 생성
- **실험 디자인 팀**: 실험 디자인과 데이터 분석 담당
  - 디자인 에이전트: 실험 방안 디자인
  - 분석 에이전트: 실험 데이터 처리, 차트 생성
- **논문 작성 팀**: 논문 작성과 수정 담당
  - 작성 에이전트: 논문 초안 작성
  - 윤문 에이전트: 언어 최적화, 표현 향상

## 작업 노드 구성

- **작업 노드 A(고성능 서버)**:
  - 워크스페이스: 실험 계산
  - 실행 에이전트: 분석 에이전트(대량 데이터 처리)
- **작업 노드 B(개인 노트북)**:
  - 워크스페이스: 문헌 조사
  - 실행 에이전트: 검색 에이전트, 정리 에이전트
- **작업 노드 C(예비 디바이스)**:
  - 워크스페이스: 논문 작성
  - 실행 에이전트: 작성 에이전트, 윤문 에이전트

## 워크플로우

1. **문헌 조사**: 작업 노드 B에서 관련 문헌 검색과 정리
2. **실험 디자인**: 실험 방안 디자인, 실험 데이터 준비
3. **데이터 분석**: 작업 노드 A에서 데이터 분석 작업 실행
4. **논문 작성**: 작업 노드 C에서 논문 작성
5. **품질 관리**: 비서실이 모든 산출물 검토하여 품질 보장
