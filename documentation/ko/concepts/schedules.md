# 일정/정기 작업

일정/정기 작업은 AI Company에서 시간 기반으로 구동되는 작업 실행 메커니즘으로, 지정된 시간에 또는 고정 주기로 자동으로 워크플로우나 작업을 실행하는 데 사용됩니다.

## 핵심 개념

### 일정(Schedule)

일정은 시간 기반 작업의 컨테이너로, 작업 실행의 시간 규칙과 실행할 내용을 정의합니다.

### 트리거 유형

일정은 여러 트리거 유형을 지원합니다:

- **일회성 트리거**: 지정된 구체적인 시간에 한 번 실행
- **주기성 트리거**: 고정 주기로 반복 실행(예: 매일, 매주, 매월 등)
- **조건 트리거**: 시간과 다른 조건을 결합하여 트리거

## 일정 구조

일정은 다음 핵심 속성을 포함합니다:

| 속성 | 설명 |
|-----|------|
| **이름** | 일정의 식별 이름 |
| **설명** | 일정의 상세 설명 |
| **트리거 규칙** | 일정이 언제 트리거되는지 정의하는 시간 표현식 |
| **실행 내용** | 일정이 트리거될 때 실행할 워크플로우 또는 작업 |
| **연관 프로젝트** | 일정이 속한 프로젝트(선택 사항) |
| **상태** | 일정의 실행 상태(활성화/비활성화) |

## 트리거 규칙

일정은 표준 cron 표현식 또는 단순화된 시간 구성을 사용하여 트리거 규칙을 정의합니다:

- **Cron 표현식**: 강력하고 유연한 시간 표현식으로, 초, 분, 시, 일, 월, 주 지원
- **단순화 구성**:
  - 매일 특정 시간
  - 매주 특정 요일과 시간
  - 매월 특정 날짜와 시간
  - 맞춤 간격(예: 2시간마다)

## 실행 내용

일정은 다음 유형의 실행 내용을 트리거할 수 있습니다:

- **워크플로우**: 완전한 워크플로우 프로세스 실행
- **단일 작업**: 특정 단일 작업 실행
- **알림 알림**: 일정 알림 알림 보내기

## 사용 시나리오

일정/정기 작업은 다음 시나리오에 적합합니다:

- **정기 보고서**: 매일/매주 자동으로 프로젝트 진행 보고서 생성
- **데이터 동기화**: 정기적으로 외부 시스템 데이터 동기화
- **백업 작업**: 정기적으로 데이터 백업 실행
- **알림 알림**: 중요한 시간 지점에 알림 보내기
- **배치 처리**: 저피크 기간에 배치 데이터 처리

## 다른 개념과의 관계

- **프로젝트**: 일정은 특정 프로젝트에 연관되어 프로젝트 컨텍스트에서 실행
- **워크플로우**: 일정은 일반적으로 워크플로우 실행을 트리거하는 데 사용
- **작업**: 일정은 직접 단일 작업 실행을 트리거할 수도 있음

## 관리 기능

일정은 다음 관리 기능을 제공합니다:

- **활성화/비활성화**: 언제든지 일정 실행 여부 제어
- **수동 트리거**: 수동으로 일정을 즉시 실행하는 것 지원
- **실행 역사**: 일정의 각 실행 상황과 결과 기록
- **실패 재시도**: 실행 실패시 자동 재시도 메커니즘
