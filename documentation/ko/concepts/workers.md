# 작업 노드

## 핵심 개념

### 작업 노드(Worker Node)

**작업 노드**는 AI Company 시스템의 기본 계산 단위로, **각 물리적 또는 가상 기기는 모두 독립적인 작업 노드**입니다.

작업 노드는 작업 공간에 실행 환경을 제공하며, 하나의 작업 공간은 동시에 여러 작업 노드에서 실행될 수 있고, 각 노드에 해당 작업 공간의 인스턴스가 있습니다.

#### 작업 노드 유형

시스템은 다음 유형의 작업 노드를 지원합니다:

| 노드 유형 | 설명 | 전형적인 시나리오 | 특징 |
|----------|------|-----------------|------|
| **Windows 개인 PC** | 데스크톱 기기 | 일상 사무, 콘텐츠 창작 | 고성능, 대화면, 완전한 입력 기기 |
