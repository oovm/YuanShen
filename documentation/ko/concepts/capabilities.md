# 능력

능력은 AI Agent의 외부 확장 기능으로, 에이전트가 외부 시스템과 상호 작용하고 리소스를 조작하며 특정 동작을 실행할 수 있게 합니다. API、MCP 등은 모두 능력의 구체적인 표현 형태입니다.

## 개념 정의

**능력**은 에이전트가 외부 세계와 상호 작용하는 확장 인터페이스로, 에이전트가 실행할 수 있는 외부 조작과 액세스할 수 있는 리소스를 정의합니다. 능력은 Agent의 내재 기술이 아니라 Agent의 외부 기능 확장입니다.

## 능력 체계

능력은 여러 카테고리로 나뉩니다:

### 1. API 통합 능력

외부 API 서비스를 호출하는 능력으로, Agent가 외부 시스템과 서비스에 액세스할 수 있게 합니다:

- **REST API**: RESTful 스타일의 API 호출
  - GET/POST/PUT/DELETE 요청
  - 요청 헤더 구성
  - 인증(Token、OAuth、API Key)
  - 응답 파싱(JSON、XML)
  - 오류 처리

- **GraphQL API**: GraphQL 인터페이스 호출
  - 쿼리(Query)
  - 변경(Mutation)
  - 구독(Subscription)
  - 변수 전달

- **WebSocket API**: 실시간 양방향 통신
  - 연결 관리
  - 메시지 송수신
  - 하트비트 유지
  - 연결 끊김 재연결

### 2. MCP 서비스 능력

MCP(Model Context Protocol) 서비스를 사용하는 능력으로, Agent가 표준화된 도구와 리소스에 액세스할 수 있게 합니다:

- **MCP 서버 연결**: MCP 서버 연결과 관리
  - 서버 발견
  - 연결 설정
  - 세션 관리
  - 건강 검사

- **MCP 도구 호출**: MCP가 제공하는 도구 호출
  - 도구 목록 가져오기
  - 도구 매개변수 구성
  - 도구 실행
  - 결과 처리

- **MCP 리소스 액세스**: MCP가 제공하는 리소스 액세스
  - 리소스 목록 가져오기
  - 리소스 내용 읽기
  - 리소스 업데이트
  - 리소스 구독

- **MCP 프롬프트 템플릿**: MCP가 제공하는 프롬프트 템플릿 사용
  - 템플릿 목록 가져오기
  - 템플릿 매개변수 채우기
  - 템플릿 렌더링

### 3. 파일 조작 능력

파일 시스템을 읽고 쓰고 관리하는 능력:

- **파일 읽기**: 파일 내용 읽기
  - 텍스트 파일 읽기
  - 바이너리 파일 읽기
  - 큰 파일 분할 읽기
  - 파일 메타정보 가져오기

- **파일 쓰기**: 파일 생성과 수정
  - 텍스트 파일 쓰기
  - 바이너리 파일 쓰기
  - 추가 쓰기
  - 파일 덮어쓰기 제어

- **파일 관리**: 파일과 디렉토리 관리
  - 파일 생성/삭제
  - 디렉토리 생성/삭제
  - 파일 이름 변경/이동
  - 파일 복사
  - 디렉토리 순회

- **파일 모니터링**: 파일 변경 모니터링
  - 파일 변경 감지
  - 디렉토리 변경 감지
  - 변경 이벤트 처리

### 4. 네트워크 액세스 능력

네트워크 리소스와 서비스에 액세스하는 능력:

- **HTTP 요청**: HTTP 요청 보내기
  - GET/POST/PUT/DELETE 등 메서드
  - 요청 헤더 설정
  - Cookie 관리
  - 리디렉션 처리
  - 프록시 지원

- **웹 페이지 스크래핑**: 웹 페이지 내용 스크래핑과 파싱
  - HTML 파싱
  - CSS 선택자
  - XPath 쿼리
  - 동적 내용 로드(JavaScript 렌더링)

- **다운로드 업로드**: 파일 다운로드와 업로드
  - 파일 다운로드
  - 중단점 재전송
  - 멀티스레드 다운로드
  - 파일 업로드

- **네트워크 진단**: 네트워크 상태 진단
  - Ping 테스트
  - 도메인 해석
  - 포트 스캔
  - 라우터 추적

### 5. 데이터베이스 액세스 능력

데이터베이스에 액세스하고 조작하는 능력:

- **관계형 데이터베이스**: SQL 데이터베이스 액세스
  - MySQL、PostgreSQL、SQLite
  - SQL 쿼리 실행
  - 트랜잭션 관리
  - 연결 풀 관리

- **NoSQL 데이터베이스**: 비관계형 데이터베이스 액세스
  - MongoDB、Redis、Elasticsearch
  - 문서 조작
  - 키-값 조작
  - 인덱스 관리

- **ORM 통합**: ORM 프레임워크 사용
  - 모델 정의
  - 쿼리 빌더
  - 관계 매핑
  - 마이그레이션 관리

### 6. 프로세스 실행 능력

외부 명령과 프로세스를 실행하는 능력:

- **명령 실행**: 시스템 명령 실행
  - 동기 실행
  - 비동기 실행
  - 환경 변수 설정
  - 작업 디렉토리 설정

- **프로세스 관리**: 프로세스 생명 주기 관리
  - 프로세스 시작
  - 프로세스 중지
  - 프로세스 모니터링
  - 프로세스 간 통신

- **Shell 스크립트**: Shell 스크립트 실행
  - Bash、PowerShell 스크립트
  - 스크립트 매개변수 전달
  - 스크립트 출력 캡처

### 7. 멀티미디어 처리 능력

이미지、오디오、비디오 등 멀티미디어를 처리하는 능력:

- **이미지 처리**: 이미지 파일 처리
  - 이미지 형식 변환
  - 이미지 크기 조정과 자르기
  - 이미지 필터 효과
  - 이미지 인식(OCR)

- **오디오 처리**: 오디오 파일 처리
  - 오디오 형식 변환
  - 오디오 자르기와 병합
  - 음성 인식(ASR)
  - 음성 합성(TTS)

- **비디오 처리**: 비디오 파일 처리
  - 비디오 형식 변환
  - 비디오 자르기와 병합
  - 비디오 스크린샷
  - 자막 처리

### 8. 정기 스케줄링 능력

정기적으로 작업을 실행하는 능력:

- **정기 작업**: 계획에 따라 작업 실행
  - Cron 표현식
  - 고정 간격
  - 일회성 실행
  - 작업 취소

- **작업 큐**: 작업 큐 관리
  - 작업 대기열에 넣기
  - 작업 대기열에서 빼기
  - 작업 우선순위
  - 작업 재시도

## 능력 구성

능력은 다음 방식으로 구성할 수 있습니다:

### 1. 활성화/비활성화

- 필요에 따라 필요한 능력 활성화
- 보안성을 높이기 위해 필요 없는 능력 비활성화
- 능력 권한 계층 제어

### 2. 매개변수 구성

- API 엔드포인트 구성
- 인증 정보 구성
- 권한 범위 구성
- 타임아웃 설정

### 3. 권한 제어

- 세밀한 권한 제어
- 조작 화이트리스트/블랙리스트
- 리소스 액세스 제한
- 감사 로그

## 능력의 역할

### 1. 기능 확장

- Agent의 기능 경계 확장
- Agent가 외부 시스템과 상호 작용할 수 있게 함
- 복잡한 비즈니스 시나리오 지원

### 2. 표준화된 인터페이스

- 표준화된 능력 인터페이스 제공
- 능력의 재사용과 공유가 쉬움
- 통합 복잡성 감소

### 3. 안전하고 제어 가능

- 능력의 활성화/비활성화 제어 가능
- 세밀한 권한 제어
- 완전한 조작 감사

## 다른 개념과의 관계

- **Agent(직원)**: Agent는 여러 능력을 구성하여 기능을 확장할 수 있음
- **기술(Skill)**: 기술은 Agent의 내재 능력, 능력은 Agent의 외부 확장
- **워크플로우(Workflow)**: 워크플로우는 Agent의 능력을 호출하여 작업을 완료할 수 있음
- **작업(Task)**: 작업 실행은 특정 능력 지원이 필요할 수 있음
