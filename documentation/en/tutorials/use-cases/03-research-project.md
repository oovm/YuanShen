# Scenario Three: Multi-Device Collaborative Research Project

## Scenario Description

A researcher conducts a complex research project using a network of worker nodes composed of multiple devices.

## Organizational Structure

- **One-person company** template
- **Secretariat**: Responsible for overall coordination and research progress control
- **Literature Research Team**: Responsible for collecting and organizing literature
  - Search Agent: Retrieves relevant literature
  - Organization Agent: Organizes literature notes and generates reviews
- **Experiment Design Team**: Responsible for experiment design and data analysis
  - Design Agent: Designs experimental protocols
  - Analysis Agent: Processes experimental data and generates charts
- **Paper Writing Team**: Responsible for paper writing and revision
  - Writing Agent: Writes the first draft of the paper
  - Polishing Agent: Optimizes language and improves expression

## Worker Node Configuration

- **Worker Node A (High-Performance Server)**:
  - Workspace: Experiment computation
  - Running Agents: Analysis Agent (processing large volumes of data)
- **Worker Node B (Personal Laptop)**:
  - Workspace: Literature research
  - Running Agents: Search Agent, Organization Agent
- **Worker Node C (Backup Device)**:
  - Workspace: Paper writing
  - Running Agents: Writing Agent, Polishing Agent

## Workflow

1. **Literature Research**: On Worker Node B, search for and organize relevant literature
2. **Experiment Design**: Design experimental protocols and prepare experimental data
3. **Data Analysis**: On Worker Node A, run data analysis tasks
4. **Paper Writing**: On Worker Node C, write the paper
5. **Quality Control**: The Secretariat reviews all outputs to ensure quality
