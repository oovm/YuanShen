# Scenario 4: Automated Customer Service Center

## Scenario Description

A small enterprise using the AI Company system to build an automated customer service center to handle customer inquiries and post-sales issues.

## Organizational Structure

- **Small Team** template
- **Secretariat**: Responsible for overall coordination and service quality control
- **Frontline Customer Service Team**: Responsible for direct customer reception
  - Reception Agent: Greet customers, understand issues
  - Classification Agent: Determine issue types, assign to appropriate teams
- **Technical Support Team**: Responsible for technical issue handling
  - Technical Agent: Answer technical questions, provide solutions
  - Escalation Agent: Handle complex issues, transfer to human when necessary
- **Post-Sales Team**: Responsible for post-sales issue handling
  - Post-Sales Agent: Handle returns, exchanges, refunds, and other issues
  - Follow-up Agent: Follow up on customer satisfaction
- **Knowledge Base Team**: Responsible for knowledge base maintenance
  - Update Agent: Update knowledge base content
  - Analysis Agent: Analyze common issues, optimize the knowledge base

## Workflow

1. **Customer Reception**: Reception Agent greets customers, understands issues
2. **Issue Classification**: Classification Agent determines issue types, assigns to appropriate teams
3. **Issue Handling**: Agents from the corresponding team handle the issues
4. **Complex Escalation**: If issues are complex, Escalation Agent intervenes or transfers to human
5. **Customer Follow-up**: Follow-up Agent follows up on customer satisfaction
6. **Knowledge Update**: Analysis Agent analyzes data, Update Agent updates the knowledge base

## Key Configurations

- Configure a friendly communication style for the Reception Agent
- Configure product knowledge and common question answers for the Technical Agent
- Configure knowledge update processes and quality standards for the Knowledge Base Team
