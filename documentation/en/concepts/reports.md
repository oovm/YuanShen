# Work Reports

Work reports are summaries of work results by AI Agents, Teams (Agent Clusters), and Tasks (Tasks) within a specific time period, including various types such as daily reports, weekly reports, and monthly reports.

## Core Concepts

### Report Types

Work reports are classified by time period into the following types:

- **Daily Report**: Daily work results summary
- **Weekly Report**: Weekly work results summary
- **Monthly Report**: Monthly work results summary
- **Custom Period Report**: Reports with custom time periods based on needs

### Report Subjects

Work reports can be generated by the following subjects:

- **AI Agent (Employee)**: Work report for an individual agent
- **Team (Agent Cluster)**: Work report for an entire team
- **Task**: Work report for a specific task
- **Project**: Work report for an entire project

## Report Structure

A work report contains the following key attributes:

| Attribute | Description |
|-----------|-------------|
| **Title** | Identifying name of the report |
| **Type** | Report type (daily/weekly/monthly/custom) |
| **Subject Type** | Report subject type (Agent/Team/Task/Project) |
| **Subject ID** | Unique identifier of the report subject |
| **Time Range** | Time interval covered by the report |
| **Content Summary** | Brief summary of the report content |
| **Work Results** | Detailed list of work results |
| **Issues and Challenges** | Issues and challenges encountered |
| **Next Steps** | Work plan for the next stage |
| **Generation Time** | Time when the report was generated |

## Report Content

Work reports typically include the following content modules:

### Work Results

- List of completed tasks
- Task completion statistics
- Key milestone achievements
- Deliverables inventory

### Issues and Challenges

- Technical issues encountered
- Resource bottlenecks
- Collaboration problems
- Risk alerts

### Next Steps

- Pending tasks
- Priority ranking
- Expected timeline
- Required resource support

## Report Generation Methods

Work reports support multiple generation methods:

### Automatic Generation

- **Scheduled Automatic Generation**: Reports automatically generated through schedules/timed tasks
- **Event-Triggered Generation**: Report generation triggered by specific events (e.g., task completion)

### Manual Generation

- **On-Demand Generation**: Users manually generate reports at any time
- **Custom Time Range**: Users specify a time range to generate reports

## Relationships with Other Concepts

- **AI Agent (Employee)**: Each Agent can generate personal work reports
- **Team (Agent Cluster)**: Each team can generate team work reports
- **Task**: Each task can generate task work reports
- **Project**: Each project can generate project work reports
- **Schedule/Timed Tasks (Schedule)**: Work reports can be automatically generated on a schedule
- **Workflow (Workflow)**: Report generation can be a step in a workflow

## Report Viewing and Sharing

Work reports provide the following features:

- **Online Viewing**: Support for viewing reports directly in the system
- **Format Export**: Support for exporting to formats such as Markdown, PDF, and HTML
- **Sharing**: Support for sharing reports with team members or project stakeholders
- **History**: Retains report historical versions and supports comparative viewing
- **Comments and Feedback**: Support for commenting on and providing feedback on reports
