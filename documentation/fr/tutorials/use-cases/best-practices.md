# Suggestions pratiques

## 1. Commencer petit

Commencez par un scénario simple, familiarisez-vous avec le système avant d'augmenter progressivement la complexité.

## 2. Tirer pleinement parti des modèles

Le système fournit une variété de modèles d'entreprise et de modèles de projet, vous pouvez choisir le modèle approprié en fonction des besoins comme point de départ.

## 3. Optimiser continuellement la configuration

Observez l'effet de travail de l'agent, optimisez continuellement sa configuration et ses compétences.

## 4. Bien utiliser le secrétariat

Le secrétariat est le cœur de l'entreprise individuelle, tirez pleinement parti de ses fonctions de coordination et de contrôle de la qualité.

## 5. Utiliser flexiblement les sous-équipes

Le mécanisme de sous-équipe permet aux agents de mieux collaborer entre eux, une utilisation flexible peut améliorer l'efficacité.
