# Flux de travail utilisateur

Ce guide présente en détail le flux de travail complet des utilisateurs lors de l'utilisation du système AI Company.

## 1. Phase de démarrage

### 1.1 Inscription et connexion
1. Accéder au site officiel d'AI Company
2. Cliquer sur le bouton « Connexion/Inscription » en haut à droite
3. Remplir les informations d'inscription, y compris le nom d'utilisateur, l'e-mail et le mot de passe
4. Vérifier l'adresse e-mail
5. Se connecter au système avec le compte enregistré

### 1.2 Téléchargement du client
1. Après une connexion réussie, cliquer sur le bouton « Commencer maintenant » sur la page d'accueil
2. Choisir la version de téléchargement correspondante en fonction de votre système d'exploitation :
   - Windows (prend en charge Windows 10/11)
   - macOS (prend en charge macOS 10.15+)
   - Linux (prend en charge les distributions principales)
3. Installer et lancer le client

### 1.3 Initialisation du nœud de travail
1. Lors du premier lancement du client, le système identifiera automatiquement l'appareil actuel en tant que nœud de travail
2. Définir un nom pour le nœud de travail (par exemple : « Mon ordinateur portable », « Serveur à la maison »)
3. Créer le premier espace de travail (par exemple : « Projet personnel », « Projet professionnel »)

## 2. Construction de l'architecture organisationnelle

### 2.1 Créer ou choisir un modèle d'entreprise
1. Accéder à l'interface « Gestion de l'entreprise »
2. Choisir un modèle d'entreprise approprié :
   - **Entreprise individuelle** : Convient aux entrepreneurs individuels et aux super individus
   - **Petite équipe** : Convient à des équipes de 3 à 10 personnes
   - **Entreprise moyenne** : Convient à des entreprises de 10 à 50 personnes
   - **Personnalisé** : Construire l'architecture organisationnelle à partir de zéro
3. Si vous choisissez le modèle « Entreprise individuelle », le système créera automatiquement un secrétariat et l'architecture organisationnelle nécessaire

### 2.2 Configurer les modèles de projet
1. Accéder à l'interface « Gestion de projet »
2. Créer un nouveau modèle de projet :
   - Définir le nom et la description du projet
   - Définir les objectifs et les livrables du projet
   - Configurer les SOP (procédures opérationnelles standard) du projet
   - Définir les jalons et les nœuds temporels du projet
3. Ou choisir un modèle de projet prédéfini par le système :
   - Développement de produit
   - Création de contenu
   - Promotion marketing
   - Service client

### 2.3 Former des équipes
1. Accéder à l'interface « Gestion d'équipe »
2. Créer l'équipe principale
3. Créer des sous-équipes selon les besoins (même un seul employé peut être géré en tant que sous-équipe)
4. Définir les responsabilités et la portée des autorisations de l'équipe
5. Configurer le flux de collaboration de l'équipe

### 2.4 Configurer les employés (agents)
1. Accéder à l'interface « Gestion des employés »
2. Créer ou choisir un modèle de compétences d'agent
3. Configurer les compétences pour l'agent :
   - Compétences professionnelles (par exemple : programmation, rédaction, conception)
   - Capacités d'utilisation d'outils (par exemple : Git, Figma, Photoshop)
   - Style de communication (par exemple : formel, concis, amical)
   - Mode de décision (par exemple : autonome, consultatif, rapports)
4. Allouer l'agent à l'équipe correspondante

## 3. Exécution du projet

### 3.1 Lancer le projet
1. Accéder à l'interface « Exécution de projet »
2. Choisir le modèle de projet à exécuter
3. Allouer le projet à une équipe (note : chaque projet ne peut être confié qu'à une seule équipe à la fois)
4. Définir les paramètres et objectifs spécifiques du projet
5. Lancer le projet

### 3.2 Surveiller l'avancement du projet
1. Consulter le tableau de bord du projet pour comprendre l'avancement global du projet
2. Consulter l'état de travail et la répartition des tâches de l'équipe
3. Consulter la situation d'exécution et les résultats de l'agent
4. Consulter la situation d'achèvement des jalons du projet

### 3.3 Intervenir et ajuster
1. Si nécessaire, donner des instructions ou fournir des commentaires à l'équipe
2. Peut ajuster les paramètres du projet ou les nœuds temporels
3. Peut appeler d'autres sous-équipes pour aider à accomplir des tâches spécifiques
4. Peut obtenir des rapports détaillés du projet via le secrétariat

### 3.4 Validation du projet
1. Après l'achèvement du projet, consulter les livrables finaux
2. Vérifier si les résultats du projet correspondent aux attentes
3. Confirmer la validation du projet
4. Sauvegarder l'expérience du projet et les meilleures pratiques

## 4. Gérer plusieurs nœuds de travail et espaces de travail

### 4.1 Ajouter de nouveaux nœuds de travail
1. Installer et se connecter au client AI Company sur un nouvel appareil
2. Le nouvel appareil s'enregistrera automatiquement en tant que nouveau nœud de travail
3. Définir un nom et une description pour le nouveau nœud de travail

### 4.2 Gérer les espaces de travail
1. Créer un nouvel espace de travail sur n'importe quel nœud de travail
2. Les espaces de travail sont isolés les uns des autres et peuvent être utilisés pour différents projets ou usages
3. Peut basculer entre différents espaces de travail
4. Peut définir les autorisations et le contrôle d'accès des espaces de travail

### 4.3 Collaboration entre nœuds
1. Les projets peuvent être répartis entre plusieurs nœuds de travail
2. Les agents peuvent s'exécuter sur différents nœuds de travail
3. Les données peuvent être synchronisées en toute sécurité entre les nœuds de travail
4. Peut surveiller l'état et l'utilisation des ressources de tous les nœuds de travail

## 5. Meilleures pratiques

### 5.1 Suggestions de flux de travail pour entreprise individuelle
1. Utiliser le modèle « Entreprise individuelle », tirer pleinement parti du rôle du secrétariat
2. Créer plusieurs espaces de travail, utilisés respectivement pour différents types de projets
3. Configurer plusieurs agents professionnels, couvrant différents domaines de compétences
4. Examiner régulièrement les résultats de travail de tous les agents via le secrétariat

### 5.2 Suggestions de gestion de projet
1. Créer des modèles de projet dédiés pour différents types de projets
2. Définir en détail les SOP du projet, s'assurer que l'agent comprend les attentes
3. Définir des jalons raisonnables, faciliter la surveillance de l'avancement du projet
4. Conserver l'expérience des projets réussis pour les projets ultérieurs

### 5.3 Suggestions de configuration d'agent
1. Configurer les compétences et le style de l'agent en fonction des besoins réels
2. Peut créer plusieurs versions de configuration pour le même agent, utilisées pour différents scénarios
3. Observer l'effet de travail de l'agent, optimiser continuellement la configuration
4. Utiliser le mécanisme de sous-équipe, faire collaborer les agents entre eux
