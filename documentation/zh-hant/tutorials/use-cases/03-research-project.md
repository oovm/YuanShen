# 場景三：多設備協同的研究專案

## 場景描述

一名研究人員，利用多台設備組成的工作節點網路，開展一個複雜的研究專案。

## 組織架構

- **一人公司**範本
- **秘書處**：負責整體協調和研究進度把關
- **文獻調研團隊**：負責收集和整理文獻
  - 檢索智慧體：檢索相關文獻
  - 整理智慧體：整理文獻筆記、產生綜述
- **實驗設計團隊**：負責實驗設計和資料分析
  - 設計智慧體：設計實驗方案
  - 分析智慧體：處理實驗數據、產生圖表
- **論文寫作團隊**：負責論文撰寫和修改
  - 寫作智慧體：撰寫論文初稿
  - 潤色智慧體：優化語言、提升表達

## 工作節點配置

- **工作節點 A（高效能伺服器）**：
  - 工作區：實驗計算
  - 執行智慧體：分析智慧體（處理大量數據）
- **工作節點 B（個人筆記型電腦）**：
  - 工作區：文獻調研
  - 執行智慧體：檢索智慧體、整理智慧體
- **工作節點 C（備用設備）**：
  - 工作區：論文寫作
  - 執行智慧體：寫作智慧體、潤色智慧體

## 工作流程

1. **文獻調研**：在工作節點 B 上，檢索和整理相關文獻
2. **實驗設計**：設計實驗方案，準備實驗數據
3. **資料分析**：在工作節點 A 上，執行資料分析任務
4. **論文撰寫**：在工作節點 C 上，撰寫論文
5. **品質把關**：秘書處審核所有產出，確保品質
