# 場景一：超級個體的內容創作工作室

## 場景描述

一名自由職業者，利用 AI Company 系統搭建自己的內容創作工作室，獨立完成從內容企劃到發布的全流程工作。

## 組織架構

- **一人公司**範本
- **秘書處**：負責整體協調、品質把關和彙報
- **內容企劃團隊**：負責選題企劃和內容規劃
  - 企劃智慧體：分析熱點、提出選題
  - 調研智慧體：收集資料、整理數據
- **內容創作團隊**：負責內容撰寫和編輯
  - 主筆智慧體：撰寫主要內容
  - 編輯智慧體：潤色、優化、校對
- **視覺設計團隊**：負責配圖和視覺元素
  - 設計智慧體：製作配圖、設計封面
- **分發營運團隊**：負責內容發布和營運
  - 營運智慧體：發布內容、管理評論、分析數據

## 工作流程

1. **專案啟動**：建立「內容創作」專案，分配給內容企劃團隊
2. **選題企劃**：企劃智慧體提出多個選題，調研智慧體收集資料
3. **內容創作**：主筆智慧體根據企劃撰寫內容，編輯智慧體潤色優化
4. **視覺製作**：設計智慧體製作配圖和封面
5. **內容分發**：營運智慧體將內容發布到各個平台
6. **數據覆盤**：營運智慧體分析數據，秘書處整理報告

## 關鍵配置

- 為每個智慧體配置專業的寫作風格和領域知識
- 為設計智慧體配置品牌視覺規範
- 為營運智慧體配置各個平台的發布規則
