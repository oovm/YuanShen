# 場景二：小型軟體產品的獨立開發

## 場景描述

一名獨立開發者，使用 AI Company 系統獨立完成一個軟體產品從需求分析到上線發布的完整開發流程。

## 組織架構

- **一人公司**範本
- **秘書處**：負責整體協調和進度把關
- **產品團隊**：負責產品規劃和設計
  - 產品經理智慧體：需求分析、產品設計、撰寫 PRD
  - UI 設計智慧體：介面設計、互動設計、製作原型
- **技術團隊**：負責開發和測試
  - 架構智慧體：技術選型、架構設計
  - 前端開發智慧體：前端程式碼撰寫
  - 後端開發智慧體：後端程式碼撰寫
  - 測試智慧體：撰寫測試案例、執行測試、報告 Bug
- **維運團隊**：負責部署和維運
  - 維運智慧體：環境配置、部署上線、監控告警

## 工作流程

1. **需求階段**：產品團隊負責需求分析和產品設計
2. **設計階段**：UI 設計智慧體製作介面設計和原型
3. **架構階段**：架構智慧體設計技術架構
4. **開發階段**：前端和後端智慧體並行開發
5. **測試階段**：測試智慧體進行全面測試
6. **部署階段**：維運智慧體部署上線
7. **監控階段**：維運智慧體持續監控系統執行

## 關鍵配置

- 為開發智慧體配置程式碼規範和最佳實務
- 為測試智慧體配置測試策略和品質標準
- 為維運智慧體配置部署流程和監控規則
