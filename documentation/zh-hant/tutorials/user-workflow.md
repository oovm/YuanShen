# 用戶工作流程

本指南詳細介紹了用戶在使用 AI Company 系統時的完整工作流程。

## 1. 入門階段

### 1.1 註冊與登入
1. 訪問 AI Company 官方網站
2. 點擊右上角「登入/註冊」按鈕
3. 填寫註冊資訊，包括用戶名、郵箱和密碼
4. 驗證郵箱地址
5. 使用註冊的帳號登入系統

### 1.2 下載客戶端
1. 登入成功後，點擊首頁「立即開始」按鈕
2. 根據您的作業系統選擇對應的下載版本：
   - Windows（支援 Windows 10/11）
   - macOS（支援 macOS 10.15+）
   - Linux（支援主流發行版）
3. 安裝並啟動客戶端

### 1.3 初始化工作節點
1. 首次啟動客戶端時，系統會自動識別當前裝置為一個工作節點
2. 為工作節點設定名稱（例如：「我的筆記型電腦」、「家裡的伺服器」）
3. 建立第一個工作區（例如：「個人專案」、「工作專案」）

## 2. 建立組織架構

### 2.1 建立或選擇公司範本
1. 進入「公司管理」介面
2. 選擇適合的公司範本：
   - **一人公司**：適合個人創業者和超級個體
   - **小型團隊**：適合 3-10 人的團隊
   - **中型企業**：適合 10-50 人的企業
   - **自訂**：從零開始建構組織架構
3. 如果選擇「一人公司」範本，系統會自動建立秘書處和必要的組織架構

### 2.2 配置專案範本
1. 進入「專案管理」介面
2. 建立新專案範本：
   - 設定專案名稱和描述
   - 定義專案目標和交付物
   - 配置專案 SOP（標準作業流程）
   - 設定專案里程碑和時間節點
3. 或選擇系統預設的專案範本：
   - 產品開發
   - 內容創作
   - 市場推廣
   - 客戶服務

### 2.3 組建團隊
1. 進入「團隊管理」介面
2. 建立主團隊
3. 根據需要建立子團隊（單個員工也可以作為子團隊管理）
4. 設定團隊的職責和權限範圍
5. 配置團隊的協作流程

### 2.4 配置員工（智慧體）
1. 進入「員工管理」介面
2. 建立或選擇智慧體技能範本
3. 為智慧體配置技能：
   - 專業技能（例如：程式設計、寫作、設計）
   - 工具使用能力（例如：Git、Figma、Photoshop）
   - 溝通風格（例如：正式、簡潔、友好）
   - 決策模式（例如：自主、諮詢、彙報）
4. 將智慧體分配到對應的團隊

## 3. 執行專案

### 3.1 啟動專案
1. 進入「專案執行」介面
2. 選擇要執行的專案範本
3. 將專案分配給一個團隊（注意：每個專案同一時間只能交給一個團隊負責）
4. 設定專案的具體參數和目標
5. 啟動專案

### 3.2 監控專案進度
1. 查看專案儀表板，了解專案整體進度
2. 查看團隊的工作狀態和任務分配
3. 查看智慧體的執行情況和產出
4. 查看專案里程碑的完成情況

### 3.3 干預和調整
1. 如果需要，可以向團隊下達指令或提供回饋
2. 可以調整專案參數或時間節點
3. 可以呼叫其他子團隊協助完成特定任務
4. 可以透過秘書處取得專案的詳細報告

### 3.4 專案驗收
1. 專案完成後，查看最終交付物
2. 審查專案成果是否符合預期
3. 確認專案驗收
4. 儲存專案經驗和最佳實踐

## 4. 管理多個工作節點和工作區

### 4.1 新增工作節點
1. 在新裝置上安裝並登入 AI Company 客戶端
2. 新裝置會自動註冊為新的工作節點
3. 為新工作節點設定名稱和描述

### 4.2 管理工作區
1. 在任意工作節點上建立新的工作區
2. 工作區之間相互隔離，可以用於不同的專案或用途
3. 可以在不同工作區之間切換
4. 可以設定工作區的權限和存取控制

### 4.3 跨節點協作
1. 專案可以在多個工作節點之間分配
2. 智慧體可以在不同工作節點上執行
3. 資料可以在工作節點之間安全同步
4. 可以監控所有工作節點的狀態和資源使用情況

## 5. 最佳實踐

### 5.1 一人公司工作流程建議
1. 使用「一人公司」範本，充分發揮秘書處的作用
2. 建立多個工作區，分別用於不同類型的專案
3. 配置多個專業智慧體，涵蓋不同的技能領域
4. 定期透過秘書處審閱所有智慧體的工作成果

### 5.2 專案管理建議
1. 為不同類型的專案建立專門的專案範本
2. 詳細定義專案 SOP，確保智慧體理解期望
3. 設定合理的里程碑，便於監控專案進度
4. 保留成功的專案經驗，用於後續專案

### 5.3 智慧體配置建議
1. 根據實際需求配置智慧體的技能和風格
2. 可以為同一個智慧體建立多個配置版本，用於不同場景
3. 觀察智慧體的工作效果，持續優化配置
4. 利用子團隊機制，讓智慧體之間相互協作
