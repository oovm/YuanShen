# 技術選型

## 概述

本文件記錄 AI Company 系統的技術選型決策，包括通訊協定、發現機制、安全標準等。

## 節點間通訊

### 發現機制

系統採用多層節點發現機制：

| 發現方式 | 技術選型 | 用途 |
|---------|---------|------|
| **區域網路發現** | mDNS/Bonjour | 自動發現本地網路節點 |
| **雲端發現** | 雲端目錄服務 | 發現遠端節點 |
| **手動連線** | 直接位址輸入 | 手動指定節點連線 |

### 通訊協定

| 協定類型 | 技術選型 | 用途 |
|---------|---------|------|
| **即時通訊** | WebSocket | 雙向即時通訊 |
| **服務呼叫** | gRPC | 高效的服務間呼叫 |
| **檔案同步** | rsync 或類似協定 | 增量檔案同步 |

### 安全通訊

| 安全機制 | 技術選型 | 說明 |
|---------|---------|------|
| **傳輸加密** | TLS 1.3 | 所有通訊加密 |
| **節點認證** | 節點憑證 | 雙向認證 |
| **資料加密** | 端到端加密 | 敏感資料端到端加密 |

## 工作節點相關技術

### 節點類型支援

系統支援以下工作節點類型：
- Windows 個人 PC
- 伺服器
- Android 手機
- iOS 手機
- 平板設備
- IoT 設備

### 節點狀態

| 狀態 | 描述 |
|------|------|
| **Online** | 節點線上且空閒 |
| **Busy** | 節點線上但忙碌 |
| **Offline** | 節點離線 |
| **Maintenance** | 節點維護中 |

## 儲存技術選型

參考 [data-models.md](./data-models.md) 了解詳細的儲存架構和技術選型。

### 資料庫選型

| 資料庫 | 用途 | 場景 |
|-------|------|------|
| **SQLite** | 輕量級關聯式資料庫 | 單機部署 |
| **PostgreSQL** | 企業級關聯式資料庫 | 生產環境 |

### 物件儲存選型

| 儲存類型 | 用途 | 場景 |
|---------|------|------|
| **檔案系統（FS）** | 本地檔案儲存 | 單機部署 |
| **S3** | 物件儲存服務 | 生產環境和雲端部署 |

## 技術選型原則

1. **開源優先**：優先選擇成熟的開源技術
2. **標準化**：遵循行業標準和最佳實務
3. **可擴展**：選擇支援水平擴展的技術
4. **安全性**：優先考慮安全性和隱私保護
5. **效能**：確保技術選型滿足效能要求
