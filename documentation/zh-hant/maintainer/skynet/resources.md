# 資源模型

資源是子網內可存取的實體，由子網維護節點儲存和管理。

## 資源屬性

| 屬性 | 說明 | 類型 |
|-----|------|------|
| **resource_id** | 資源唯一 ID | 字串 |
| **resource_type** | 資源類型 | 字串（如 file/image/document/link 等，開放類型） |
| **name** | 資源名稱 | 字串 |
| **description** | 資源描述 | 字串（可選） |
| **content_hash** | 資源內容雜湊 | blake3 雜湊（用於驗證完整性） |
| **content_uri** | 資源內容儲存位置 | URI（可選，如 IPFS CID、本地儲存等） |
| **size** | 資源大小 | 整數（位元組） |
| **created_at** | 建立時間 | 時間戳 |
| **created_by** | 建立者 | user_id |
| **updated_at** | 更新時間 | 時間戳（可選） |
| **updated_by** | 更新者 | user_id（可選） |
| **version** | 版本號 | 整數 |
| **permissions** | 權限設定 | JSON 物件（可選） |
| **metadata** | 自訂元資料 | JSON 物件（可選） |

## 資源類型

資源類型是開放的字串標識，常見範例：

| 資源類型 | 說明 |
|---------|------|
| **file** | 通用檔案 |
| **image** | 圖片檔案 |
| **document** | 文件檔案 |
| **video** | 影片檔案 |
| **audio** | 音訊檔案 |
| **link** | 連結資源 |

## 資源操作

- **資源上傳**：建立新資源，計算 content_hash，儲存內容
- **資源下載**：根據 resource_id 取得資源，驗證 content_hash
- **資源更新**：更新資源內容，增加版本號，保留歷史版本
- **資源刪除**：標記資源為已刪除（軟刪除）
- **資源查詢**：搜尋和篩選資源清單

## 資源權限

- 資源建立者可設定存取權限
- 支援唯讀、讀寫、管理等權限級別
- 可授權給特定使用者、角色或整個頻道

## 子網隔離原則

- 資源**不跨子網**共用，資源僅在所屬子網內可存取
- 如需跨子網使用資源，必須**複製**到目標子網，而非直接引用
- 複製後，目標子網中的副本擁有獨立的生命週期和權限
