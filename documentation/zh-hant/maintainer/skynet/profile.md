# 使用者元資訊（Profile）

使用者元資訊描述使用者的公開資訊，包括頭像、暱稱、個人簡介、線上狀態等。

## 元資訊屬性

| 屬性 | 說明 | 類型 |
|-----|------|------|
| **user_id** | 使用者 ID | user_id |
| **subnet_id** | 子網 ID | subnet_id |
| **avatar** | 頭像 | 資源引用或 URL（可選） |
| **nickname** | 暱稱 | 子網內顯示名稱（可選） |
| **bio** | 個人簡介 | 字串（可選） |
| **status_text** | 自訂狀態文字 | 字串（可選，如"正在開會"、"外出吃飯"） |
| **presence_status** | 線上狀態 | 列舉（online/busy/away/offline，可選） |
| **last_active_at** | 最後活躍時間 | 時間戳（可選） |
| **updated_at** | 元資訊更新時間 | 時間戳（可選） |
| **device_info** | 裝置資訊 | JSON 物件（可選，如裝置類型、作業系統等） |

## 線上狀態類型

| 狀態 | 說明 | 圖示 |
|-----|------|------|
| **online** | 使用者當前活躍，正在使用客戶端 | 🟢 |
| **busy** | 使用者線上但忙碌，可能無法及時回覆 | 🔴 |
| **away** | 使用者線上但離開一段時間（如 5 分鐘無操作） | 🟡 |
| **offline** | 使用者不在線或沒有活動連線 | ⚪ |

## 線上狀態更新機制

### 客戶端觸發更新

- **上線**：客戶端連接到服務節點時，自動設定為"online"狀態
- **活躍**：使用者有操作（傳送訊息、查看頻道等）時，更新最後活躍時間
- **離開**：客戶端偵測到使用者一段時間（如 5 分鐘）無操作時，自動設定為"away"狀態
- **忙碌**：使用者可手動設定為"busy"狀態
- **下線**：客戶端中斷連線時，自動設定為"offline"狀態

### 服務節點管理

- 服務節點維護使用者的線上狀態
- 透過心跳機制偵測使用者是否在線
- 狀態變化時，廣播給相關使用者（如同一頻道的成員）

## 元資訊可見性

- 使用者元資訊在子網內公開可見
- 可設定誰能看到元資訊：
  - 所有人
  - 僅聯絡人
  - 僅同一頻道成員
  - 自訂
- 敏感欄位（如 device_info）可單獨設定可見性

## 元資訊操作

- **查看元資訊**：查看其他使用者的元資訊
- **更新元資訊**：更新自己的頭像、暱稱、個人簡介
- **設定線上狀態**：手動設定自己的線上狀態（online/busy/away）
- **設定狀態文字**：設定自訂狀態文字
- **清除狀態**：清除自訂狀態，使用預設狀態

## 通知機制

- 使用者元資訊變化時，可選擇性地通知相關使用者
- 支援狀態變化通知開關
- 可設定關注特定使用者的元資訊變化

## 隱私考量

- 使用者元資訊是公開的，但不包含敏感資訊
- 可選擇隱藏線上狀態
- 裝置資訊是可選的，使用者可選擇不共用
- 支援元資訊部分隱藏（如只顯示暱稱，不顯示頭像）
