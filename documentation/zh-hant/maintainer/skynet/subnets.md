# 子網模型

## 子網標識

每個子網擁有唯一 ID `subnet_id = blake3(任意位元組)`，可由建立者生成。主網是預定義的子網，ID 固定為全零（`0x00...`）。

## 子網類型

子網類型是一個開放的字串標識，用於區分子網的功能和用途，客戶端可以根據子網類型決定是否載入和如何處理該子網。

**常見的子網類型範例**：

| 子網類型 | 說明 | 用途範例 |
|---------|------|---------|
| **organization** | 組織子網 | 用於組織、公司的通訊和協作 |
| **community** | 社群子網 | 用於普通社群、興趣小組的通訊 |
| **private** | 私有子網 | 用於小型私密群組通訊 |

**子網類型的作用**：
- 客戶端可以根據子網類型決定是否載入和如何處理該子網
- 不同類型的子網可以有不同的功能特性和權限策略
- 客戶端可以根據類型選擇性地載入和顯示子網
- 子網類型是開放的，應用可以定義自己的類型

## 子網元資訊

每個子網包含元資訊，用於描述子網的基本屬性和功能：

| 屬性 | 說明 | 類型 |
|-----|------|------|
| **subnet_type** | 子網類型 | 字串（開放類型，如 organization/community/private） |
| **subnet_version** | 子網類型版本 | 字串（如 "1.0.0"） |
| **name** | 子網名稱 | 字串 |
| **description** | 子網描述 | 字串（可選） |
| **icon** | 子網圖示 | URL 或雜湊（可選） |
| **created_at** | 建立時間 | 時間戳 |
| **created_by** | 建立者 | user_id |
| **features** | 功能特性清單 | 字串陣列（可選） |
| **metadata** | 自訂元資料 | JSON 物件（可選） |

**子網元資訊的作用**：
- 客戶端透過 `subnet_type` 判斷是否支援該子網
- `subnet_type_version` 用於版本相容性檢查
- `features` 清單宣告子網支援的功能特性
- `metadata` 可用於儲存類型特定的擴充資訊

## 子網模型概念

Skynet 採用子網模型，每個獨立的通訊系統或社群都是一個子網：
- 每個子網有自己的使用者、聯絡人、群組
- 使用者可以同時加入多個子網，使用同一個 `auth_id`
- 每個子網有獨立的聯絡人和群組（聯絡人是子網內部概念）

## 子網核心標識

Skynet 作為去中心化通訊協定，子網有三個核心標識：

| 標識 | 說明 | 作用 |
|-----|------|------|
| **auth_id** | 使用者全域身分 ID | 跨子網唯一標識使用者，類似真名。**Skynet 協定的最高機密，僅用於身分認證，絕不應在子網內部資料中洩露或儲存。** |
| **user_id** | 使用者在子網內的本地 ID | 子網內本地標識，類似暱稱/網名，用於隱私保護。**子網內部所有資料只使用 user_id。** |
| **channel_id** | 頻道/群組 ID | 標識子網內的一個聊天群組或頻道 |

## 子網資料

每個子網維護以下資料，並採用**多節點複製**儲存：

### 1. 子網元資訊

- **subnet_type**：子網類型（開放字串，如 organization/community/private）
- **subnet_type_version**：子網類型版本
- **name**：子網名稱
- **description**：子網描述（可選）
- **icon**：子網圖示（可選）
- **created_at**：建立時間
- **created_by**：建立者的 user_id
- **features**：功能特性清單（可選）
- **metadata**：自訂元資料（可選）

### 2. 成員清單
- **user_id**：使用者在子網內的本地 ID（子網內唯一，可選）
- **身分公鑰**：使用者的 Ed25519 公鑰（用於驗證簽章）
- **角色**：管理員 / 普通成員
- **加入時間**：使用者加入子網的時間
- **裝置公鑰清單**：使用者在該子網內使用的裝置公鑰（用於端到端加密）
- **聯絡人清單**：該使用者在子網內的聯絡人（子網內部概念，只使用 user_id）
- **使用者元資訊（Profile）**：
  - **avatar**：頭像（資源引用或 URL，可選）
  - **nickname**：暱稱（子網內顯示名稱，可選）
  - **bio**：個人簡介（可選）
  - **status_text**：自訂狀態文字（如"正在開會"、"外出吃飯"，可選）
  - **presence_status**：線上狀態（online/busy/away/offline，可選）
  - **last_active_at**：最後活躍時間（時間戳，可選）
  - **updated_at**：元資訊更新時間（時間戳，可選）
  - **device_info**：裝置資訊（JSON 物件，可選，如裝置類型、作業系統等）

**注意**：`auth_id` 僅用於初始身分認證，絕不應儲存在子網成員清單或任何子網內部資料中。

### 2.1 子網模式：開放 vs 封閉
子網支援兩種執行模式：
| 模式 | 說明 | 適用場景 |
|------|------|---------|
| **封閉子網** | 加入需要管理員審核，防止女巫攻擊 | 企業、組織、私密社群 |
| **開放子網** | 任何人可自由加入，無需審核 | 公開社群、興趣小組 |

子網建立時指定模式，後續可由管理員修改。

### 3. 頻道清單
- **channel_id**：頻道/群組的唯一 ID
- **頻道名稱**：群組名稱
- **建立者**：建立者的 user_id
- **建立時間**：建立時間
- **成員清單**：頻道成員的 user_id 清單
- **頻道類型**：私聊 / 群聊 / 公告頻道

### 4. 權限策略
- 誰可以添加/移除成員
- 誰可以建立/刪除頻道
- 誰可以修改頻道資訊

### 5. 資源（Resource）

資源是子網內可存取的實體，由子網維護節點儲存和管理。詳見 [資源模型](./resources.md)。

### 6. 資訊（Message）

資訊是子網內傳遞的內容單元，用於使用者間通訊。詳見 [訊息模型](./messages.md)。

## 子網維護節點

每個子網由一組服務節點（稱為**維護節點**）負責儲存和同步資料。建立子網時，建立者可指定初始維護節點（通常是自己信任的節點），後續可透過子網內投票或管理員指派增加/移除維護節點。

維護節點之間透過**拜占庭容錯複製**保持資料一致。
