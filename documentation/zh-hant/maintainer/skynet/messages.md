# 訊息模型

訊息是子網內傳遞的內容單元，用於使用者間通訊。

## 訊息屬性

| 屬性 | 說明 | 類型 |
|-----|------|------|
| **message_id** | 訊息唯一 ID | 字串 |
| **channel_id** | 頻道 ID | 頻道 ID（群聊）或空（私聊） |
| **sender_id** | 發送者 ID | user_id |
| **recipient_id** | 接收者 ID | user_id（私聊時使用） |
| **message_type** | 訊息類型 | 字串（如 text/image/file/resource 等，開放類型） |
| **content** | 訊息內容 | 結構化資料（JSON 物件或加密的結構化資料） |
| **content_encrypted** | 是否加密 | 布林值 |
| **resource_refs** | 資源引用清單 | resource_id 陣列（可選） |
| **reply_to** | 回覆的訊息 ID | message_id（可選） |
| **thread_id** | 討論串 ID | message_id（可選，用於訊息討論串） |
| **mentions** | 提及清單 | 提及物件陣列（可選） |
| **is_pinned** | 是否置頂 | 布林值（可選，預設 false） |
| **pinned_at** | 置頂時間 | 時間戳（可選） |
| **pinned_by** | 置頂者 ID | user_id（可選） |
| **status** | 訊息狀態 | 字串（可選，如 sending/sent/delivered/read/recalled） |
| **delivered_at** | 送達時間 | 時間戳（可選） |
| **read_at** | 已讀時間 | 時間戳（可選） |
| **created_at** | 建立時間 | 時間戳 |
| **edited_at** | 編輯時間 | 時間戳（可選） |
| **deleted_at** | 刪除時間 | 時間戳（可選，軟刪除） |
| **metadata** | 自訂元資料 | JSON 物件（可選） |

## 訊息類型

訊息類型是開放的字串標識，常見範例：

| 訊息類型 | 說明 |
|---------|------|
| **text** | 文字訊息 |
| **image** | 圖片訊息 |
| **file** | 檔案訊息 |
| **resource** | 資源引用訊息 |
| **link** | 連結訊息 |
| **system** | 系統訊息 |

## 訊息內容格式

- 訊息內容是**結構化資料**（通常為 JSON 物件）
- 不是固定的 Markdown 或 HTML 格式
- 客戶端根據 `message_type` 和 `content` 結構自主決定如何渲染
- 文字內容可以包含 Markdown、HTML 等格式標籤，但這由客戶端選擇是否解析和渲染

### 訊息類型內容結構範例

- **text**：文字訊息
  - content 包含 `text` 欄位（純文字、Markdown、HTML 等，由客戶端決定渲染方式）
- **image**：圖片訊息
  - content 包含 `resource_id` 欄位引用圖片資源
  - 可選包含 `caption` 欄位（圖片說明）
- **file**：檔案訊息
  - content 包含 `resource_id` 欄位引用檔案資源
  - 可選包含 `filename`、`size` 等元資料
- **resource**：資源引用訊息
  - content 包含 `resource_id` 欄位
- **link**：連結訊息
  - content 包含 `url` 欄位
  - 可選包含 `title`、`description`、`preview_image` 等預覽資訊
- **system**：系統訊息（如成員加入、頻道建立等）
  - content 包含 `event_type`、`event_data` 等欄位

## 訊息操作

- **訊息傳送**：傳送訊息到頻道或私聊，端到端加密（可選）
- **訊息接收**：從維護節點取得新訊息
- **訊息編輯**：編輯已傳送的訊息，保留編輯歷史
- **訊息刪除**：標記訊息為已刪除（軟刪除）
- **訊息回覆**：回覆特定訊息
- **訊息歷史**：取得頻道或私聊的歷史訊息

## 訊息安全

- 支援端到端加密，只有通訊雙方能解密
- 訊息內容雜湊用於完整性驗證
- 發送者簽章用於身分驗證
- 服務節點無法存取加密的訊息內容

## 子網隔離原則

- 訊息**不跨子網**傳遞，每個子網是獨立的通訊域
- 如需跨子網轉發訊息，必須**複製**到目標子網，而非直接引用
- 複製後，目標子網中的副本擁有獨立的生命週期

## 訊息狀態管理（可選擴充）

子網可選擇啟用訊息狀態追蹤功能，提供更豐富的訊息體驗：

| 狀態 | 說明 |
|-----|------|
| **發送中** | 訊息已提交到維護節點，正在處理 |
| **已傳送** | 訊息已儲存到維護節點，等待接收 |
| **已送達** | 訊息已推送給接收者的線上裝置 |
| **已讀** | 接收者已閱讀該訊息 |
| **已撤回** | 發送者已撤回該訊息 |

### 訊息狀態操作（可選）

- **狀態更新**：接收者裝置線上時，自動更新為"已送達"
- **已讀回執**：接收者閱讀訊息後，傳送已讀通知（可選）
- **訊息撤回**：發送者在一定時間內可撤回訊息（可選）
- **狀態可見性**：可設定誰能看到訊息狀態（僅發送者/僅雙方/所有人）

## 訊息表情反應（Reaction）

訊息表情反應是使用者對訊息的情感回饋。

### 反應屬性

| 屬性 | 說明 | 類型 |
|-----|------|------|
| **reaction_id** | 反應唯一 ID | 字串 |
| **message_id** | 目標訊息 ID | message_id |
| **user_id** | 添加反應的使用者 | user_id |
| **emoji** | 表情 | 字串（如 "👍"、"❤️"、"🎉"）或自訂表情 ID |
| **created_at** | 添加時間 | 時間戳 |

### 反應操作

- **添加反應**：使用者對訊息添加表情反應
- **撤銷反應**：使用者撤銷自己添加的反應
- **查詢反應**：取得某訊息的所有反應清單
- **查看使用者**：查看添加了特定表情的使用者清單

### 反應特性

- 支援標準 Unicode 表情
- 支援自訂表情（需在子網層級定義）
- 同一使用者對同一訊息只能添加一次相同表情
- 同一使用者對同一訊息可以添加多個不同表情

## 訊息置頂（Pin）

訊息置頂用於標記重要訊息，使其在頻道或私聊頂部顯示。

### 置頂屬性

| 屬性 | 說明 | 類型 |
|-----|------|------|
| **pin_id** | 置頂唯一 ID | 字串 |
| **message_id** | 被置頂的訊息 ID | message_id |
| **channel_id** | 頻道 ID | 頻道 ID（群聊）或空（私聊） |
| **pinned_by** | 置頂者 ID | user_id |
| **pinned_at** | 置頂時間 | 時間戳 |
| **order** | 排序位置 | 整數（可選，用於手動排序） |

### 置頂操作

- **置頂訊息**：將訊息置頂到頻道或私聊頂部
- **取消置頂**：取消訊息的置頂狀態
- **取得置頂清單**：取得頻道或私聊的所有置頂訊息
- **調整順序**：調整置頂訊息的顯示順序

### 置頂權限

- 可設定誰有權限置頂訊息：
  - 僅管理員
  - 僅訊息發送者
  - 所有成員
  - 自訂角色

## 訊息討論串（Thread）

訊息討論串用於在特定訊息下進行深入討論，不影響主聊天串流。

### 討論串屬性

| 屬性 | 說明 | 類型 |
|-----|------|------|
| **thread_id** | 討論串 ID | message_id（即父訊息的 message_id） |
| **parent_message_id** | 父訊息 ID | message_id |
| **channel_id** | 頻道 ID | 頻道 ID（群聊）或空（私聊） |
| **created_by** | 討論串建立者 | user_id |
| **created_at** | 討論串建立時間 | 時間戳 |
| **message_count** | 討論串內訊息數量 | 整數 |
| **last_message_at** | 最後訊息時間 | 時間戳 |

### 討論串訊息

討論串中的訊息與普通訊息類似，但有以下區別：
- 討論串訊息的 `thread_id` 欄位設定為父訊息的 `message_id`
- 討論串訊息在 UI 中獨立顯示
- 可折疊/展開討論串

### 討論串操作

- **建立討論串**：在某訊息下建立回覆討論串
- **傳送討論串訊息**：在討論串內傳送訊息
- **查看討論串**：查看討論串內的所有訊息
- **折疊/展開討論串**：控制討論串的顯示狀態
- **討論串通知**：可設定是否接收討論串內訊息的通知

## 訊息提及（Mention）

訊息提及用於提醒特定使用者或群組。

### 提及物件類型

| 類型 | 說明 | 範例 |
|-----|------|------|
| **user** | 提及特定使用者 | @alice |
| **channel** | 提及頻道所有成員 | @所有人、@channel |
| **role** | 提及特定角色 | @管理員、@開發組 |

### 提及屬性

| 屬性 | 說明 | 類型 |
|-----|------|------|
| **mention_type** | 提及類型 | user/channel/role |
| **mention_id** | 提及物件 ID | user_id 或 role_id |
| **mention_name** | 提及顯示名稱 | 字串 |
| **offset** | 在文字中的起始位置 | 整數（可選，用於文字高亮） |
| **length** | 在文字中的長度 | 整數（可選，用於文字高亮） |

### 提及操作

- **添加提及**：在訊息中添加提及
- **解析提及**：客戶端解析訊息中的提及
- **傳送通知**：被提及的使用者收到通知
- **高亮顯示**：被提及的部分在訊息中高亮顯示

### 提及內容結構範例

對於 text 類型的訊息，content 可以包含：
```json
{
  "text": "大家好，@alice 請查看這個文件",
  "mentions": [
    {
      "mention_type": "user",
      "mention_id": "user_123",
      "mention_name": "alice",
      "offset": 5,
      "length": 6
    }
  ]
}
```
