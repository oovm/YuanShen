# 團隊（Team）：Agent Groups

### 概念定義

**團隊**是一組智慧體（Agent）的組合，他們為了共同的目標而協作。團隊定義了智慧體之間的角色分工、協作方式和溝通規則。

### 核心要素

#### 基本資訊
- **團隊名稱**：團隊的標識性名稱
- **團隊描述**：詳細的團隊介紹
- **團隊類型**：職能型 / 專案型 / 矩陣型 / 虛擬型
- **團隊成員**：團隊包含的智慧體列表

#### 角色分工
- **團隊領導**：負責整體協調和決策
- **專家成員**：負責特定領域的專業工作
- **協調成員**：負責團隊內外的溝通協調
- **支援成員**：提供輔助性支援工作

#### 協作模式
- **彙報關係**：誰向誰彙報
- **決策機制**：如何做出決策
- **溝通管道**：使用什麼方式溝通
- **會議節奏**：定期會議的安排

#### 團隊文化
- **協作原則**：團隊成員如何協作
- **衝突處理**：如何處理分歧和衝突
- **知識共享**：如何分享知識和經驗
- **團隊精神**：團隊的凝聚力建設

#### 子團隊管理
- **子團隊概念**：團隊可以包含子團隊，子團隊必須是完整的團隊
- **子團隊呼叫**：團隊可以根據需要呼叫子團隊完成特定任務
- **靈活配置**：子團隊必須是完整的團隊，即便只有一個智慧體也要包裝成團隊
- **層級協作**：支援多層級的子團隊嵌套和協作

### 團隊範本的作用

1. **最優組合**
   - 基於任務需求選擇合適的智慧體組合
   - 不同技能的智慧體互補
   - 形成 1+1&gt;2 的協作效果

2. **協作規範**
   - 明確的角色和責任
   - 標準化的協作流程
   - 減少協作摩擦

3. **可重用性**
   - 成功的團隊配置可以保存為範本
   - 類似任務可以直接使用相同團隊
   - 快速組建高效團隊

### 範例：產品開發團隊範本

```
產品開發團隊
├── 產品經理（AI）
│   ├── 角色：團隊領導
│   ├── 職責：需求分析、優先級排序、進度管理
│   └── 技能：產品思維、使用者研究、專案管理
├── 架構師（AI）
│   ├── 角色：技術專家
│   ├── 職責：系統設計、技術選型、程式碼審查
│   └── 技能：系統架構、設計模式、技術趨勢
├── 開發者（AI）
│   ├── 角色：執行成員
│   ├── 職責：程式碼實現、單元測試、文件編寫
│   └── 技能：程式語言、框架使用、最佳實務
├── 測試員（AI）
│   ├── 角色：質量保證
│   ├── 職責：測試計畫、測試執行、Bug 追蹤
│   └── 技能：測試方法、質量標準、自動化測試
└── 維運師（AI）
    ├── 角色：維運支援
    ├── 職責：部署配置、監控告警、故障處理
    └── 技能：DevOps、雲端服務、系統管理
```
