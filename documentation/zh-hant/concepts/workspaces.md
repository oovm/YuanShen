# 工作區

## 核心概念

### 工作區（Workspace）

**工作區**是 AI Company 系統中用於隔離和組織不同任務、專案或環境的邏輯單元。**工作區可以跨多個工作節點存在和執行**，實現真正的分散式協同。

工作區不再限於單個節點，而是一個可以跨越裝置邊界的邏輯實體。

#### 工作區的作用

1. **環境隔離**
   - 不同工作區的資料和設定相互隔離
   - 避免任務之間的干擾
   - 支援獨立的安全策略

2. **跨節點協同**
   - 工作區可以同時在多個節點上執行
   - 智慧體可以在不同節點間遷移和協作
   - 資料自動在多個節點間同步

3. **資源分配**
   - 為每個工作區分配特定的資源（可跨節點）
   - 限制資源使用，防止資源耗盡
   - 優先級排程

4. **上下文管理**
   - 儲存工作區的上下文狀態
   - 快速切換不同的工作場景
   - 支援工作區的暫停和恢復

#### 工作區類型

| 工作區類型 | 用途 | 特點 |
|-----------|------|------|
| **個人工作區** | 個人日常使用 | 完全私有、彈性設定 |
| **專案工作區** | 特定專案協作 | 可共享、版本控制 |
| **智慧體工作區** | AI 智慧體執行 | 自動管理、資源最佳化 |
| **安全工作區** | 敏感任務處理 | 最高安全等級、稽核追蹤 |
| **臨時工作區** | 短期任務 | 自動清理、生命週期短 |

#### 工作區-節點關係

```
工作區（跨節點）
│
├── 工作節點 1 (Windows PC)
│   ├── 工作區實例 A
│   │   ├── 智慧體 1
│   │   └── 本地資料快取
│   └── 工作區實例 B
│       └── ...
│
├── 工作節點 2 (Android 手機)
│   └── 工作區實例 A
│       ├── 智慧體 2（遷移自節點 1）
│       └── 本地資料快取
│
└── 工作節點 3 (伺服器)
    └── 工作區實例 A
        ├── 智慧體 3（背景執行）
        └── 完整資料副本
```

## 工作區管理

### 工作區建立

1. **建立方式**
   - 手動建立：使用者主動建立工作區
   - 自動建立：根據任務需求自動建立
   - 範本建立：基於預設範本建立

2. **工作區設定**
   ```
   工作區設定 {
     name: 工作區名稱
     type: personal | project | agent | secure | temp
     nodeIds: [關聯節點列表]  // 可跨多個節點
     resources: {
       cpu: CPU 限制（跨節點總和）
       memory: 記憶體限制（跨節點總和）
       storage: 儲存限制（跨節點總和）
     }
     security: {
       encryption: 是否加密
       accessControl: 存取控制
     }
     lifecycle: {
       autoCleanup: 是否自動清理
       ttl: 生存時間
     }
     distribution: {
       preferredNodes: [優先節點]
       failoverNodes: [故障轉移節點]
       replicationStrategy: full | partial | selective
     }
   }
   ```

### 工作區分佈策略

1. **主-從模式**
   - 一個主節點負責協調
   - 其他節點作為副本
   - 適合讀寫分離場景

2. **對等模式**
   - 所有節點地位平等
   - 資料在節點間複製
   - 適合高可用性場景

3. **分片模式**
   - 工作區資料分片到不同節點
   - 每個節點負責一部分資料
   - 適合大規模資料場景

### 工作區切換

1. **快速切換**
   - 一鍵切換工作區
   - 儲存當前上下文
   - 恢復目標工作區狀態

2. **並行工作區**
   - 支援多個工作區同時執行
   - 工作區間資源隔離
   - 可設定工作區優先級

### 工作區同步

1. **跨節點同步**
   - 工作區資料在多個節點間自動同步
   - 增量同步，減少頻寬
   - 衝突解決策略

2. **選擇性同步**
   - 可選擇同步的節點
   - 可設定同步方向
   - 支援離線編輯

3. **智慧體遷移**
   - 智慧體可以在工作區的不同節點間遷移
   - 保持智慧體狀態和上下文
   - 根據資源情況自動排程

## 節點實例管理

每個工作區在關聯的節點上都有一個實例：

| 實例狀態 | 描述 |
|---------|------|
| **Active** | 實例活躍，正在執行智慧體 |
| **Standby** | 實例待命，資料同步中 |
| **Offline** | 節點離線，資料待同步 |
| **Failed** | 實例異常，需要恢復 |

## 安全模型

### 工作區安全

- **工作區加密**：工作區資料加密儲存
- **存取控制**：細粒度的存取權限控制
- **稽核日誌**：完整的操作稽核記錄
- **節點授權**：控制哪些節點可以加入工作區

## 與工作流的關係

工作區為工作流提供執行環境，工作流在工作區內執行。工作流可以跨工作區的多個節點實例執行，實現分散式任務流轉。

詳見 [工作流](./workflows.md) 文件了解更多。
