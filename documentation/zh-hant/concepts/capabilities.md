# 能力

能力是 AI Agent 的外部擴充功能，使智慧體能夠與外部系統互動、操作資源和執行特定動作。API、MCP 等都是能力的具體表現形式。

## 概念定義

**能力**是智慧體與外部世界互動的擴充介面，定義了智慧體能夠執行的外部操作和存取的資源。能力不是 Agent 的內在技能，而是 Agent 的外部功能擴充。

## 能力體系

能力分為多個類別：

### 1. API 整合能力

呼叫外部 API 服務的能力，使 Agent 能夠存取外部系統和服務：

- **REST API**：呼叫 RESTful 風格的 API
  - GET/POST/PUT/DELETE 請求
  - 請求頭設定
  - 認證（Token、OAuth、API Key）
  - 回應解析（JSON、XML）
  - 錯誤處理

- **GraphQL API**：呼叫 GraphQL 介面
  - 查詢（Query）
  - 變更（Mutation）
  - 訂閱（Subscription）
  - 變數傳遞

- **WebSocket API**：即時雙向通訊
  - 連線管理
  - 訊息收發
  - 心跳保活
  - 斷線重連

### 2. MCP 服務能力

使用 MCP（Model Context Protocol）服務的能力，使 Agent 能夠存取標準化的工具和資源：

- **MCP 伺服器連線**：連線和管理 MCP 伺服器
  - 伺服器發現
  - 連線建立
  - 會話管理
  - 健康檢查

- **MCP 工具呼叫**：呼叫 MCP 提供的工具
  - 工具列表取得
  - 工具參數設定
  - 工具執行
  - 結果處理

- **MCP 資源存取**：存取 MCP 提供的資源
  - 資源列表取得
  - 資源內容讀取
  - 資源更新
  - 資源訂閱

- **MCP 提示範本**：使用 MCP 提供的提示範本
  - 範本列表取得
  - 範本參數填充
  - 範本渲染

### 3. 檔案操作能力

讀寫和管理檔案系統的能力：

- **檔案讀取**：讀取檔案內容
  - 文字檔案讀取
  - 二進位檔案讀取
  - 大檔案分塊讀取
  - 檔案元資訊取得

- **檔案寫入**：建立和修改檔案
  - 文字檔案寫入
  - 二進位檔案寫入
  - 追加寫入
  - 檔案覆蓋控制

- **檔案管理**：管理檔案和目錄
  - 檔案建立/刪除
  - 目錄建立/刪除
  - 檔案重新命名/移動
  - 檔案複製
  - 目錄遍歷

- **檔案監控**：監控檔案變化
  - 檔案變更監聽
  - 目錄變更監聽
  - 變更事件處理

### 4. 網路存取能力

存取網路資源和服務的能力：

- **HTTP 請求**：發送 HTTP 請求
  - GET/POST/PUT/DELETE 等方法
  - 請求頭設定
  - Cookie 管理
  - 重新導向處理
  - 代理支援

- **網頁抓取**：抓取和解析網頁內容
  - HTML 解析
  - CSS 選擇器
  - XPath 查詢
  - 動態內容載入（JavaScript 渲染）

- **下載上傳**：檔案下載和上傳
  - 檔案下載
  - 斷點續傳
  - 多執行緒下載
  - 檔案上傳

- **網路診斷**：網路狀態診斷
  - Ping 測試
  - 域名解析
  - 連接埠掃描
  - 路由追蹤

### 5. 資料庫存取能力

存取和操作資料庫的能力：

- **關聯式資料庫**：存取 SQL 資料庫
  - MySQL、PostgreSQL、SQLite
  - SQL 查詢執行
  - 交易管理
  - 連線池管理

- **NoSQL 資料庫**：存取非關聯式資料庫
  - MongoDB、Redis、Elasticsearch
  - 文件操作
  - 鍵值操作
  - 索引管理

- **ORM 整合**：使用 ORM 框架
  - 模型定義
  - 查詢建構
  - 關係對應
  - 遷移管理

### 6. 行程執行能力

執行外部命令和行程的能力：

- **命令執行**：執行系統命令
  - 同步執行
  - 非同步執行
  - 環境變數設定
  - 工作目錄設定

- **行程管理**：管理行程生命週期
  - 行程啟動
  - 行程停止
  - 行程監控
  - 行程間通訊

- **Shell 腳本**：執行 Shell 腳本
  - Bash、PowerShell 腳本
  - 腳本參數傳遞
  - 腳本輸出擷取

### 7. 多媒體處理能力

處理圖片、音訊、視訊等多媒體的能力：

- **影像處理**：處理圖片檔案
  - 圖片格式轉換
  - 圖片縮放裁切
  - 圖片濾鏡效果
  - 圖片辨識（OCR）

- **音訊處理**：處理音訊檔案
  - 音訊格式轉換
  - 音訊剪輯合併
  - 語音辨識（ASR）
  - 語音合成（TTS）

- **視訊處理**：處理視訊檔案
  - 視訊格式轉換
  - 視訊剪輯合併
  - 視訊截圖
  - 字幕處理

### 8. 定時排程能力

定時執行任務的能力：

- **定時任務**：按計劃執行任務
  - Cron 運算式
  - 固定間隔
  - 一次性執行
  - 任務取消

- **任務佇列**：管理任務佇列
  - 任務入列
  - 任務出列
  - 任務優先級
  - 任務重試

## 能力設定

能力可以透過以下方式設定：

### 1. 啟用/停用

- 按需啟用需要的能力
- 停用不需要的能力以提高安全性
- 能力權限分級控制

### 2. 參數設定

- API 端點設定
- 認證資訊設定
- 權限範圍設定
- 逾時設定

### 3. 權限控制

- 細粒度權限控制
- 操作白名單/黑名單
- 資源存取限制
- 稽核日誌

## 能力的作用

### 1. 功能擴充

- 擴充 Agent 的功能邊界
- 使 Agent 能夠與外部系統互動
- 支援複雜的業務場景

### 2. 標準化介面

- 提供標準化的能力介面
- 便於能力的複用和共享
- 降低整合複雜度

### 3. 安全可控

- 能力的啟用/停用可控
- 細粒度的權限控制
- 完整的操作稽核

## 與其他概念的關係

- **Agent（員工）**：Agent 可以設定多種能力來擴充功能
- **技能（Skill）**：技能是 Agent 的內在能力，能力是 Agent 的外部擴充
- **工作流（Workflow）**：工作流可以呼叫 Agent 的能力來完成任務
- **任務（Task）**：任務執行可能需要特定的能力支援
