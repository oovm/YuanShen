# 員工（Employee）：Agent

員工（Employee）是一個由**技能合集**組成的智慧體（Agent），定義了智慧體能做什麼、擅長做什麼、以及如何與其他智慧體協作。

## 概念定義

**員工**是技能的容器和組合體，透過組合不同的技能來形成完整的工作能力。員工本身不是技能，而是技能的集合。

## 核心要素

### 基本資訊

- **員工名稱**：智慧體的標識性名稱
- **員工頭像**：視覺標識
- **職位**：智慧體的角色定位
- **描述**：詳細的能力介紹
- **角色類型**：智慧體的角色分類

### 技能合集

員工透過組合多種技能來形成工作能力：

- **核心技能**：基礎能力（溝通、推理、學習、記憶等）
- **專業技能**：特定領域的專業能力（程式設計、分析、設計等）
- **工具技能**：使用特定工具的能力（開發工具、設計工具、辦公工具等）
- **軟技能**：人際交往和團隊協作能力

詳見 [skills.md](skills.md) 了解詳細的技能體系。

### 能力配置

員工可以配置多種能力來擴展其功能：

- **API 整合能力**：呼叫外部 API 的能力
- **MCP 服務能力**：使用 MCP（Model Context Protocol）服務的能力
- **檔案操作能力**：讀寫檔案的能力
- **網路存取能力**：存取網路資源的能力

詳見 [capabilities.md](capabilities.md) 了解詳細的能力體系。

### 工作風格

- **回應速度**：快速回應 / 深思熟慮
- **決策方式**：果斷決策 / 充分諮詢
- **溝通風格**：簡潔直接 / 詳細解釋
- **風險偏好**：敢於冒險 / 謹慎保守

## 員工的作用

### 1. 技能組合

- 將多個技能組合成完整的工作能力
- 技能之間協同配合，形成合力
- 靈活應對各種任務場景

### 2. 能力標準化

- 清晰定義智慧體的能力邊界
- 便於使用者選擇合適的智慧體
- 可以評估和比較不同智慧體

### 3. 持續進化

- 智慧體可以學習新技能
- 技能可以不斷提升和優化
- 可以添加新的能力擴展
- 適應新的需求和場景

## 範例：全端開發者智慧體

```

├── 基本資訊
│   ├── 名稱：Alex

│   └── 簡介：5年開發經驗，擅長 Web 應用開發
├── 技能合集
│   ├── 核心技能
│   │   ├── 溝通能力：進階
│   │   ├── 推理能力：專家級
│   │   ├── 學習能力：進階
│   │   └── 記憶能力：進階
│   ├── 專業技能
│   │   ├── 前端開發（React/Vue/TypeScript）：專家級
│   │   ├── 後端開發（Node.js/Python）：進階
│   │   ├── 資料庫設計：專家級
│   │   └── API 設計：進階
│   ├── 工具技能
│   │   ├── Git：專家級
│   │   ├── VS Code：專家級
│   │   ├── Docker：進階
│   │   └── CI/CD：進階
│   └── 軟技能
│       ├── 團隊協作：進階
│       ├── 程式碼審查：專家級
│       └── 技術文件：進階
├── 能力配置
│   ├── API 整合能力：啟用
│   ├── MCP 服務能力：啟用
│   ├── 檔案操作能力：啟用
│   └── 網路存取能力：啟用
└── 工作風格
    ├── 回應速度：快速回應
    ├── 決策方式：果斷決策
    ├── 溝通風格：詳細解釋

```
